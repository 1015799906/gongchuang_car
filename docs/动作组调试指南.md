## 一、硬件坐标系

### 三个执行器

| 执行器 | CAN地址 | 范围 | 含义 |
|--------|---------|------|------|
| 平推（pingtui） | 6 | [-20, 65] | 前伸/后缩，正值=向前伸出 |
| 升降（shengjiang） | 5 | [0, 135] | 升降台，正值=升高 |
| 云台（yuntai） | ？ | 角度制 | 腰部旋转，用 `normalize_yaw` 归一化 |

### 辅助外设

| 外设 | 说明 |
|------|------|
| 抓手（zhuashou） | PWM控制，二值：`set_zhuashou_he()` 合（抓）、`set_zhuashou_kai()` 开（放） |
| 物块平台（wukuaipingtai） | 5个位置，`set_wukuaipingtai_weizhi(1~5)` |
| 加热（heat） | 0=关，默认300=开 |

### 颜色编码

| 代码 | 颜色 | 对应云台角度 | 宏 |
|------|------|-------------|-----|
| R / 1 | 红 | 90° | `ACT_YT_RIGHT_RING_DEG` |
| G / 2 | 绿 | 120° | `ACT_YT_CENTER_RING_DEG` |
| B / 3 | 蓝 | 150° | `ACT_YT_LEFT_RING_DEG` |

### 全局参数宏（motor_ack_test.c 第72-88行）

```c
ACT_PING_SPEED   1000    // 平推电机速度
ACT_PING_ACC     200     // 平推电机加速度
ACT_LIFT_SPEED   1000    // 升降电机速度
ACT_LIFT_ACC     200     // 升降电机加速度
ACT_YT_SPEED     13.0    // 云台旋转速度
ACT_X_RACK       50.0    // 货架取货时平推位置
ACT_X_PLACE      10.0    // 放置时平推位置
ACT_H_RACK       60.0    // 取货时升降高度
ACT_H_PLACE      60.0    // 放置时升降高度
ACT_H_TRANSFER   10.0    // 过渡高度（防撞安全高度）
ACT_X_SAFE       0.0     // 安全位置平推
ACT_H_SAFE       0       // 安全位置升降
ACT_YT_SAFE_DEG  0.0     // 安全位置云台角度
ACT_YT_PLACE_RACK_DEG  0.0   // 货架放置时云台角度
```

## 二、所有 ACT 命令一览

| 命令 | 格式 | 说明 |
|------|------|------|
| `ACT STOP` | 无参数 | 急停：停止所有运动 + 关加热 |
| `ACT ZERO` | 无参数 | 升降归零 + 平推当前位置清零 |
| `ACT SAFE` | 无参数 | 回安全位姿：平推=0、升降=0、云台=0、抓手开、平台回1号位 |
| `ACT RESET` | 同 SAFE | 同上（别名） |
| `ACT JIXIE` | 同 SAFE | 同上（别名） |
| `ACT RACK` | 无参数 | 货架待命位姿：平推=ACT_X_RACK、升降=ACT_H_RACK、云台=0 |
| `ACT PICK <1/2/3>` | 取物 | 平台转到指定位置 + 货架待命 + 抓手闭合 |
| `ACT PLATFORM <1/2/3>` | 选料 | 仅旋转物块平台到指定位置 |
| `ACT OPEN` | 无参数 | 抓手张开 |
| `ACT CLOSE` | 无参数 | 抓手闭合 |
| `ACT HEAT ON` | 加热开 | 加热值=ACT_HEAT_COMPARE(300) |
| `ACT HEAT OFF` | 加热关 | 加热值=0 |
| `ACT HEAT <0~1999>` | 加热设定 | 自定义加热比较值 |
| `ACT POSE <ping> <lift> <yaw>` | 手动位姿 | 三轴同时运动到绝对位置（PID_SCALE格式） |
| `ACT NA <R/G/B>` | 拿物料 | 从货架取对应颜色物料 |
| `ACT FANG <R/G/B>` | 放物料 | 放对应颜色物料到货架 |
| `ACT FANGMD <R/G/B>` | 放多 | 放物料变体（多物料场景） |
| `ACT YTNA <R/G/B>` | 圆台拿 | 从圆台取对应颜色物料 |
| `ACT NA1 <R/G/B>` | 拿变体1 | 仅移动到圆台前对应位置 |
| `ACT NA2 <R/G/B>` | 拿变体2 | 从圆台拿物料（不同路径） |
| `ACT ROUND3` | 无参数 | 三轮全流程：平台1→2→3 依次取放 |

## 三、每个动作的详细执行序列

### 3.1 `ACT SAFE` — 回安全位

```
1. 关加热
2. 停止所有运动
3. 抓手张开
4. 物块平台回1号位
5. 平推送 0、升降送 0、云台转 0°
```

### 3.2 `ACT RACK` — 货架待命

```
平推送 ACT_X_RACK(50)、升降送 ACT_H_RACK(60)、云台转 0°
```

### 3.3 `ACT NA` — 拿物料（act_na）

**颜色=R(1)：右侧红环**
```
1. act_pose( 3.0, 130, 90°)    → 平推微出、升到130高、转90°对齐右侧环
2. 抓手闭合                      → 抓住物料
3. act_pose(-50.0, 50, 90°)    → 缩回平推、降到50高、保持90°
4. act_pose(ACT_X_RACK, ACT_H_TRANSFER, 0°)   → 到货架待命位（过渡高度）
5. act_rack_ready()                                      → 货架待命
6. 抓手张开                                               → 把物料放在货架上
```

**颜色=G(2)：中间绿环**
```
1. act_pose(-10.0, 130, 120°)   → 平推微缩、升到130高、转120°
2. act_pose(-50.0, 130, 120°)   → 进一步缩回（靠近物料）
3. 抓手闭合
4. act_pose(-50.0, 50, 120°)    → 降到50高
5. act_pose(ACT_X_RACK, ACT_H_TRANSFER, 0°)   → 货架待命
6. act_rack_ready()
7. 抓手张开
```

**颜色=B(3)：左侧蓝环**
```
1. act_pose( 3.0, 110, 150°)    → 平推微出、升到110高、转150°
2. act_pose( 3.0, 130, 150°)    → 升到130高
3. 抓手闭合
4. act_pose( 8.0, 25, 150°)     → 平推微出、降到25高
5. act_pose(ACT_X_RACK, ACT_H_TRANSFER, 0°)   → 货架待命
6. act_rack_ready()
7. 抓手张开
```

### 3.4 `ACT FANG` — 放物料（act_fang）

**颜色=R(1)：**
```
1. act_rack_ready()
2. act_pose(4.0, 25, 90°)      → 平推4、升25高、转90°
3. act_pose(4.0, 132, 90°)     → 升到132高
4. 抓手张开                      → 放下物料
```

**颜色=G(2)：**
```
1. act_rack_ready()
2. act_pose(-20.0, 25, 0°)     → 缩回、降25高、转0°
3. act_pose(-20.0, 25, 120°)   → 转120°
4. act_pose(-50.0, 132, 120°)  → 继续缩回、升到132高
5. 抓手张开
```

**颜色=B(3)：**
```
1. act_rack_ready()
2. act_pose(8.8, 25, 150°)     → 平推8.8、降25高、转150°
3. act_pose(8.8, 132, 150°)    → 升到132高
4. 抓手张开
```

### 3.5 `ACT FANGMD` — 放多变体（act_fang_maduo）

与 FANG 不同，使用了反向（负值）平推路径。

**颜色=R(1)：**
```
1. act_rack_ready()
2. act_pose(3.0, 25, 90°)
3. act_pose(3.0, 60, 90°)     ← 只升到60，不像FANG升到132
4. 抓手张开
```

**颜色=G(2)：**
```
1. act_rack_ready()
2. act_pose(ACT_X_RACK, 25, 0°)
3. act_pose(-120.0, 25, 120°)  ← 大幅缩回
4. act_pose(-50.0, 60, 120°)
5. 抓手张开
```

**颜色=B(3)：**
```
1. act_rack_ready()
2. act_pose(ACT_X_RACK, 25, 0°)
3. act_pose(-120.0, 25, 150°)  ← 大幅缩回
4. act_pose(3.0, 60, 150°)
5. 抓手张开
```

### 3.6 `ACT YTNA` — 圆台拿（act_yuantai_na）

**颜色=R(1)：**
```
1. 抓手张开
2. act_pose(-100.0, 50, 120°)  → 大幅缩回、升50高、转120°（中间）
3. 抓手闭合
4. act_pose(ACT_X_RACK, ACT_H_TRANSFER, 0°)
5. act_rack_ready()
6. 抓手张开
```

**颜色=G(2)：**
```
1. 抓手张开
2. act_pose(63.0, 48, 150°)    → 大幅前伸、升48高、转150°（左侧）
3. 抓手闭合
4. act_pose(20.0, 25, 150°)
5. act_pose(-20.0, 25, 0°)
6. act_pose(ACT_X_RACK, ACT_H_TRANSFER, 0°)
7. act_rack_ready()
8. 抓手张开
```

**颜色=B(3)：**
```
1. 抓手张开
2. act_pose(63.0, 48, 90°)     → 大幅前伸、升48高、转90°（右侧）
3. 抓手闭合
4. act_pose(ACT_X_RACK, ACT_H_TRANSFER, 0°)
5. act_rack_ready()
6. 抓手张开
```

### 3.7 `ACT NA1` — 拿变体1（仅移动，不抓取）

```
颜色=R(1): act_pose(40.0, 0, 120°)
颜色=G(2): act_pose(63.0, 18, 150°)
颜色=B(3): act_pose(63.0, 18, 90°)
```

注意：NA1 不闭合抓手、不缩回、不回到货架。只是一个单纯的移动命令。

### 3.8 `ACT NA2` — 拿变体2（act_yuantai_na2）

与 YTNA 几乎相同，但颜色=R 时路径有所不同（不回到货架？）。实际代码中 YTNA 和 NA2 的颜色逻辑基本一致。

### 3.9 `ACT ROUND3` — 三轮全流程

```
1. 物块平台=1，取放红环（90°）
2. 物块平台=2，取放绿环（120°）
3. 物块平台=3，取放蓝环（150°）
4. 平推归零、升降归零
```

## 四、调动作组的顺序

### 第一阶段：标定零点和极限

1. **`ACT ZERO`** — 确认升降和平推零点正确。升降归零后位置应为 0，平推当前位置清零。
2. **`ACT SAFE`** — 确认安全位姿：平推=0、升降=0、云台=0 时机械是否到家。
3. **手动测极限** — 用 `SJ` 和 `PT` 命令分别测升降和平推的最大安全行程，更新 `SHENGJIANG_MAX_POS`、`PINGTUI_MIN_POS`、`PINGTUI_MAX_POS`。

### 第二阶段：标定关键点位

用 `ACT POSE <ping> <lift> <yaw>` 手动测试，反复微调，记录每个关键点的数值：

| 点位 | 含义 | 当前值 | 你需要测的 |
|------|------|--------|-----------|
| 货架取货高度 | 平推伸到货架前、对正物料 | H=60, X=50 | 测实际 |
| 货架放置高度 | 放到货架上的高度 | H=60, X=10 | 测实际 |
| 右侧圆环角度 | 云台对正右侧环 | 90° | 测实际 |
| 中间圆环角度 | 云台对正中间环 | 120° | 测实际 |
| 左侧圆环角度 | 云台对正左侧环 | 150° | 测实际 |
| 过渡高度 | 移动时不撞东西的安全高度 | H=10 | 测实际 |

### 第三阶段：逐个调动作

按以下顺序逐个验证：

1. **`ACT RACK`** — 只有一个位姿，确认平推和升降到货架前正确
2. **`ACT NA R`** — 拿红色物料，观察抓取高度、前后位置、抓手时机
3. **`ACT FANG R`** — 放红色物料，确认放置高度
4. **`ACT NA G`**、**`ACT FANG G`** — 绿色
5. **`ACT NA B`**、**`ACT FANG B`** — 蓝色
6. **`ACT YTNA`** — 圆台拿，多个圆台场景
7. **`ACT FANGMD`** — 多物料场景
8. **`ACT ROUND3`** — 最后联调全流程

### 第四阶段：调速度

每个动作调通后再调速度：

- `ACT_PING_SPEED` / `ACT_PING_ACC` — 平推太快会撞飞物料，太慢浪费时间
- `ACT_LIFT_SPEED` / `ACT_LIFT_ACC` — 同
- `ACT_YT_SPEED` — 云台速度，太快惯性大会过冲

## 五、每个动作调什么

以 `act_na` 和 `act_fang` 为例：

### act_na(code) — 拿物料

```
act_pose(3.0, 130, 90°)    ← "靠近物料"位姿
         ↑     ↑    ↑
       平推  升降  云台
```

- **平推值**：决定前后距离，太大撞物料、太小抓不到
- **升降值**：决定取料高度，太大抓空气、太小顶物料
- **云台值**：决定旋转方向，必须对准圆环

然后：
```
抓手闭合                     ← 时机：是否到位置后再停顿一下才抓？
act_pose(-50.0, 50, 90°)   ← "缩回"位姿，把物料从环上取下来
act_pose(RACK, TRANSFER, 0°) ← "转场到货架"
抓手张开                     ← "放到货架上"
```

### act_fang(code) — 放物料

逻辑相反：先到货架位置，再到放置高度，张开抓手。

## 六、调试技巧

### 6.1 逐步执行

调动作组时不要直接跑全套。用单个位姿命令逐步验证：

```
ACT POSE 3.0 130 90    ← 手动到"取红料"的位置，看机械到不到位
```

到位后，再发下一句。全部确认完再改宏定义。

### 6.2 速度先慢后快

第一次调动作时把速度和加速度调低（比如 speed=500, acc=100），确认路径不撞车后再恢复正常速度。

### 6.3 抓手时机

如果抓手提前合上（物料没到就抓了），需要在两个 `act_pose` 之间加 `delay_ms1`。当前代码里没有显式延时——`move_all` 内部会计算时间并 `delay_ms1(max_time)`，所以每个 `act_pose` 是阻塞完成的。问题只会出现在"物料到位后抓手立刻合"的瞬间——如果机械有惯性，需要加一个小延时。

### 6.4 镜像注意

左右侧的平推值可能不对称。代码中 R 和 B 的平推值不同（R=3.0, B=8.8），如果你换了机械平台结构，需要重新测。

### 6.5 中间环的特殊路径

颜色=G(绿色/中间) 的 `act_na` 走两段平推：先 `-10` 再 `-50`，这是为了从正面逼近中间环。如果你的中间环位置变了，需要同时改这两个值。

## 七、与 race_task.c 的关系

`motor_ack_test.c` 里的动作函数是调试版。正式比赛用 `race_task.c` 里的对应函数，且 `race_task.c` 有自己的宏定义：

```c
// race_task.c 第12-15行
#define YT_PLACE_RACK_DEG  0.0f
#define YT_RIGHT_RING_DEG  90.0f
#define YT_CENTER_RING_DEG 120.0f
#define YT_LEFT_RING_DEG   150.0f
```

注意：`race_task.c` 的宏和 `motor_ack_test.c` 的 `ACT_YT_*` 宏是**两套独立的**。调完 motor_ack_test 后，记得把 `race_task.c` 里的对应数值也同步更新。
