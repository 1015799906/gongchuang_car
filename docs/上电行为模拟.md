# 三版固件上电行为模拟

> 模拟烧录后第一次上电（或按复位键），从 STM32 启动到进入主循环的全过程。
> 每个时间节点标注了：**谁会动、什么声音、LED状态、串口输出**。

---

## 场景设定

- 机器人放在平地上，各执行器处于**任意初始位置**（上电前不做任何手动归位）
- 升降处于半高度位置（比如 30mm 左右）
- 平推处于中间位置
- 舵机保持上次断电时的角度
- DAPLink 已拔掉或不影响

---

# 固件1：wuliu（主固件/比赛固件）

```
文件：STM32f407_wuliu/Core/Src/main.c
启动条件：上电 / 按复位 / 烧录后自动复位
```

## 时间线

```
T+0ms   上电，STM32 启动
        无动静。

T+10ms  HAL_Init() 完成
        无动静。

T+20ms  SystemClock_Config() 完成
        168MHz 主频就绪。
        无动静。

T+50ms  MX_GPIO_Init() 完成
        ├── LED0(PF9) 和 LED1(PF10) 输出低电平
        └── 无动静。

T+100ms MX_CAN1_Init() 完成
        CAN1 外设就绪，但滤波器未配，电机不收指令。
        无动静。

T+150ms MX_TIM2_Init() 完成
        ├── TIM2 配置就绪（PWM周期20ms）
        ├── CH2/CH3/CH4 的 PWM 输出此刻还未启动！
        └── ➜ 舵机不动！

T+200ms MX_TIM3_Init() 完成
        TIM3 CH1 加热PWM 就绪，但未启动输出。
        无动静。

T+250ms MX_TIM4_Init() 完成
        TIM6/TIM5 依次完成。
        无动静。

T+300ms MX_UART5_Init() + USART1/2/6 完成
        四个串口就绪，中断未武装。
        无动静。

T+350ms ┌─────────────────────────────────────────────┐
        │ 进入 main() 用户代码区                       │
        └─────────────────────────────────────────────┘

        HAL_GPIO_WritePin(LED0, RESET)  → LED0 亮
        HAL_GPIO_WritePin(LED1, SET)    → LED1 亮

T+360ms host_init()
        武装 HOST_UART(USART1) 单字节接收中断。
        从此上位机可以发送数据。
        无动静。

T+370ms race_chassis_init()  ← 第一次动静！
        │
        ├── can_filter_start()
        │   CAN1 滤波器配好，启动接收中断。
        │   电机可以收指令了。
        │   无动静。
        │
        ├── HAL_TIM_PWM_Start(&htim3, CH1)
        │   加热 PWM 开始输出，当前值为 0 → 不热。
        │   无动静。
        │
        ├── race_actuator_reset_all()  ← 动！
        │   │
        │   ├── set_zhuashou_kai()
        │   │   HAL_TIM_PWM_Start(TIM2, CH2)  ← 夹爪PWM首次输出
        │   │   夹爪从任意位置跳转到 50°（开爪位）
        │   │   ➜ 听到 "嗡~" 一声，夹爪张开
        │   │
        │   ├── set_wukuaipingtai_weizhi(1)
        │   │   HAL_TIM_PWM_Start(TIM2, CH3)  ← 置物盘PWM首次输出
        │   │   置物盘从任意角度慢速旋转到 0°（工位1）
        │   │   约需 150ms × (角度差÷20) = 视当前位置
        │   │   ➜ 听到 "滋滋" 软启动声
        │   │
        │   ├── set_yuantai_Angle(0, 300ms)
        │   │   HAL_TIM_PWM_Start(TIM2, CH4)  ← 云台PWM首次输出
        │   │   云台从任意角度慢速旋转到 0°（置物架方向）
        │   │   每步20PWM×20ms = 约需数秒
        │   │   ➜ 听到 "滋...滋...滋..." 步进声
        │   │
        │   ├── pingtui_control(0, 1000, 200)
        │   │   平推电机(地址6)收到归零指令
        │   │   如果当前位置 ≠ 0mm → 电机转动
        │   │   ➜ 听到电机 "嗡嗡" 声，平推手回收
        │   │
        │   ├── race_pingtui_clear_zero()
        │   │   平推软件位置 + 驱动器位置清零
        │   │   无动静。
        │   │
        │   └── race_shengjiang_homezero()  ← 最大动静！！
        │       shengjiang_homezero_run()
        │       1. 清除CAN缓冲
        │       2. 使能升降电机(地址5)
        │       3. 配置回零参数: 模式2, dir=1↑, 750mA, 30ms
        │       4. 触发回零 → 升降电机向上全速运动！
        │       5. 轮询等待，直到碰顶限位
        │       6. 碰顶 → 停止 → 清零位置
        │       ➜ 升降电机从中间位置猛冲到顶部！
        │       ➜ "嗡——————咔！" （持续数秒）
        │       ➜ 这是上电后最大最危险的动作！
        │
        ├── race_heat_set(0) → 加热关
        │
        └── race_chassis_init 完成

T+5~10s (取决于升降初始位置)
        race_chassis_init() 全部完成
        所有执行器处于：
        ├── 夹爪：开
        ├── 置物盘：工位1（0°）
        ├── 云台：0°（置物架方向）
        ├── 平推：0mm（回收）
        ├── 升降：0mm（顶部）
        └── 加热：关

T+5s~   race_wait_host_ready()
        LED1 闪烁（200ms亮/200ms灭）  ← 表示等待握手
        循环检查 USART1 是否收到 "987654321"
        
        此刻机器人完全静止，只有LED1在闪。
        你需要在上位机启动后，它自动发 "987654321"。
        
        也可以手动测试：
        python host_task_probe.py --port COMx --send "987654321"

        收到握手后 → LED1 常亮 → 进入下一步

T+5s~   race_wait_switch()
        LED1 闪烁（50ms亮/50ms灭）  ← 表示等待开关
        循环检查 PC9 是否为低电平
        
        你按下开关（或释放开关）后：
        PC9 变低 → 跳出等待

T+?     进入主循环 race_task_run()
        执行全部 9 个阶段的比赛流程。
        LED 在最后阶段慢闪（500ms）。
        
        期间通过 USART1 不断和上位机交互：
        发 '1' → 等待 → 收到坐标 → 运动 → 发 '2' → ...
```

## 预期现象总结 (wuliu)

| 时刻 | 看到什么 | 听到什么 | LED |
|------|----------|----------|-----|
| 上电瞬间 | 无 | 无 | 全灭→LED0+LED1亮 |
| ~0.5s | 夹爪张开、置物盘转、云台转 | "滋滋"舵机声 | 不变 |
| ~1s | 平推手回收 | 电机"嗡嗡"声 | 不变 |
| ~1-10s | **升降猛冲到顶** | **"嗡——咔！"** | 不变 |
| 之后 | 全部静止 | 安静 | LED1 闪烁 |
| 握手后 | 静止 | 安静 | LED1 常亮 |
| 按开关后 | 开始比赛流程 | 各种运动声 | 按阶段变化 |

# 固件2：wuliu_debug（调试固件）

```
文件：STM32f407_wuliu_debug/Core/Src/main.c
```

> **和 wuliu 完全一样！**
> 启动流程、执行器归零、等待握手、比赛流程 —— 全部相同。
> 唯一区别：CAN接收回调、TIM4回调被空函数替代，IMU未编译。
> 所以升降回零和舵机初始化时的动静**和 wuliu 完全一样**。

## 预期现象总结 (wuliu_debug)

**和 wuliu 一模一样**。唯一的区别是比赛流程中 PID 姿态控制不可用（因为 CAN 回调和 TIM4 回调被禁用了），底盘旋转可能不工作，但**上电时的执行器动静完全相同**。

# 固件3：motor_test（电机测试固件）★ 你现在用的

```
文件：STM32f407_wuliu_motor_test/Core/Src/main.c
```

## 时间线（修改后版本：已注释开机HOMEZERO）

```
T+0ms   上电
        ↓ （外设初始化和 wuliu 一样，略过）
T+350ms 进入 main() 用户代码区

        HAL_GPIO_WritePin(LED0, RESET)  → LED0 亮
        HAL_GPIO_WritePin(LED1, SET)    → LED1 亮

T+360ms motor_ack_test_init()  ← 动静从这里开始
        │
        ├── HAL_TIM_PWM_Start(TIM2, CH2)
        ├── HAL_TIM_PWM_Start(TIM2, CH3)
        ├── HAL_TIM_PWM_Start(TIM2, CH4)
        │   三个舵机 PWM 同时启动！
        │   初始值 = MX_TIM2_Init 里的默认值：
        │     CH2=520, CH3=648, CH4=1500
        │   从这个"非预期"位置瞬间跳到默认PWM位置
        │   ➜ 听到一声短暂的 "嗡"（几百微秒级别，几乎感觉不到）
        │
        ├── servo_defaults()
        │   立即把 PWM 设为目标值：
        │     CH2=862（开爪）, CH3=500（工位1）, CH4=500（0°）
        │   从 CH4=1500→500 有一个大跳变！
        │   ➜ 如果云台之前不在0°附近，会有一次快速旋转
        │   ➜ 约需几百毫秒（取决于当前角度差）
        │   注意：servo_defaults 用的是 __HAL_TIM_SET_COMPARE 直接赋值，
        │   没有软启动！是一次性跳到目标PWM！
        │   ➜ "嗡！"的一声，舵机快速归位
        │
        ├── shengjiang_set_current_pos(0.0f)
        │   软件变量，不动。
        │
        ├── imu_init()
        │   USART2 和 IMU 握手。不动。
        │
        ├── PIDInit()
        │   软件变量。不动。
        │
        ├── CAN 滤波器 + 启动
        │   电机可收指令。不动。
        │
        ├── ~~shengjiang_homezero_default("BOOT")~~  ← 已注释！
        │   原来这里升降会猛冲到顶。
        │   修改后：不动！安静！
        │
        ├── pingtui_set_current_pos(0.0f)
        ├── zdt_clear_pos(PINGTUI_ADDR)
        │   软件清零。不动。
        │
        └── emit_status()
            通过 UART5 发送初始状态信息
            串口终端可以看到：
              # STATUS: servo CH2=862 CH3=500 CH4=500
              # SJ pos=0.000 ...
              # IMU yaw=xxx pitch=xxx roll=xxx
              ...

T+1s    motor_ack_test_init() 完成
        进入主循环 motor_ack_test_poll()

        此时机器人状态：
        ├── 夹爪：开（862 PWM ≈ 50°）
        ├── 置物盘：工位1（500 PWM ≈ 0°）
        ├── 云台：0°（500 PWM ≈ 0° 方向）
        ├── 升降：未归零，停在当前位置
        ├── 平推：未归零，停在当前位置
        ├── LED0: 亮，LED1: 亮
        └── 串口终端：显示初始状态

        机器人静止，等待你通过串口输入命令。

        你现在应该手动执行：
        STATUS          ← 确认状态OK
        SJ HOMEZERO     ← 手动升降回零（此时开始运动！）
        PUSH HOME       ← 手动平推回零
```

# 你的 motor_test 现在上电应该看到什么

```
1. 上电 → LED0和LED1同时亮
2. 听到一声短暂的"嗡"（舵机归位，~0.5s内完成）
3. 串口终端输出初始状态信息
4. 机器人完全静止
5. 没有任何电机会自动运动 ← 这是修改后的效果
6. 你输入 SJ HOMEZERO → 升降才开始回零运动
7. 你输入 PUSH HOME → 平推才开始回零运动
```

如果上电后看到的和上面描述不一致（比如舵机一直在转、升降自动动了），那就是修改没生效或者烧录的是旧版本。
