## 1. 硬件准备与连线

### 1.1 硬件清单

| 组件 | 型号/规格 | 数量 |
|------|-----------|------|
| 主控板 | STM32F407ZGT6 (LQFP144) | 1 |
| 上位机 | RDK X5 (或树莓派) | 1 |
| 调试器 | Horco CMSIS-DAP | 1 |
| 底盘电机 | ZDT系列 CAN步进电机 x4 | 4 |
| 升降电机 | ZDT系列 CAN步进 (地址5) | 1 |
| 平推电机 | ZDT系列 CAN步进 (地址6) | 1 |
| 夹爪舵机 | 270°舵机 (TIM2 CH2) | 1 |
| 置物盘舵机 | 270°舵机 (TIM2 CH3) | 1 |
| 云台舵机 | 360°舵机 (TIM2 CH4) | 1 |
| IMU | 维特智能 (WitMotion), 串口 | 1 |
| 二维码摄像头 | USB摄像头 | 1 |
| 上方摄像头 | USB摄像头 | 1 |

### 1.2 关键连线

```
STM32F407:
  PA9  (TX) → 上位机 RX           # 串口通信, 115200
  PA10 (RX) → 上位机 TX
  PA11       → CAN收发器 RX        # CAN总线, 500Kbps
  PA12       → CAN收发器 TX
  PD5  (TX) → IMU RX              # IMU, 115200
  PD6  (RX) → IMU TX
  PA1        → 夹爪舵机信号线       # PWM
  PA2        → 置物盘舵机信号线
  PA3        → 云台舵机信号线
  PC9        → 触发开关 (低电平触发)
  PC12 (TX) → USB转串口 RX         # 调试口, 115200

CAN总线:
  CAN_H → 所有ZDT电机驱动的CAN_H
  CAN_L → 所有ZDT电机驱动的CAN_L

供电:
  电机驱动: 24V DC
  STM32板:  5V (经稳压)
  舵机:     5~7.4V (独立供电)
```

## 2. 开发环境搭建

### 2.1 固件开发环境 (WSL + Windows)

**前提：** Windows 10/11 + WSL2 (推荐Ubuntu)

**工具链安装：**

在 Windows 上安装 STM32CubeIDE 或独立工具链：
```
路径(默认):
  CMake:    C:\Users\<用户名>\AppData\Local\stm32cube\bundles\cmake\<版本>\bin\cmake.exe
  GCC:      C:\Users\<用户名>\AppData\Local\stm32cube\bundles\gnu-tools-for-stm32\<版本>\bin\
  OpenOCD:  D:\ST\STM32CubeIDE_2.0.0\STM32CubeIDE\plugins\com.st.stm32cube.ide.mcu.externaltools.openocd.win32_<版本>\tools\bin\openocd.exe
```

**首次配置：** 修改 `cfg.sh` 中的路径为你本机的实际路径：
```bash
CMAKE_EXE_WIN="C:\\Users\\你的用户名\\AppData\\Local\\stm32cube\\bundles\\cmake\\...\\bin\\cmake.exe"
GCC_BIN_WIN="C:\\Users\\你的用户名\\AppData\\Local\\stm32cube\\bundles\\gnu-tools-for-stm32\\...\\bin"
```

同样修改 `flash.sh` 中的 OpenOCD 路径：
```bash
OPENOCD_EXE="D:\\ST\\STM32CubeIDE_2.0.0\\STM32CubeIDE\\plugins\\...\\openocd.exe"
OPENOCD_SCRIPTS="D:\\ST\\STM32CubeIDE_2.0.0\\STM32CubeIDE\\plugins\\...\\openocd\\st_scripts"
```

## 3. 固件构建与烧录

### 3.1 选择正确的固件版本

| 使用场景 | 目录 | 何时使用 |
|----------|------|----------|
| **正式比赛** | `STM32f407_wuliu/` | 比赛当天，只跑完整任务流程 |
| **现场调试** | `STM32f407_wuliu_debug/` | 赛前准备，要调整参数/测试硬件 |
| **硬件标定** | `STM32f407_wuliu_motor_test/` | 首次上电，逐项验证所有硬件 |

### 3.2 构建固件

```bash
# 进入对应目录
cd STM32f407_wuliu          # 或 STM32f407_wuliu_debug / STM32f407_wuliu_motor_test

# 首次构建（配置CMake）
./cfg.sh

# 构建
./build.sh

# 成功后输出
# built: build/win-debug/STM32f407_wuliu.elf
```

### 3.3 烧录固件

**准备工作：**
1. CMSIS-DAP 调试器连接 STM32 的 SWD 口 (SWCLK + SWDIO + GND)
2. 调试器插到电脑 USB
3. STM32 板子已上电

**烧录命令：**
```bash
./flash.sh
```

**成功输出：**
```
Programming Finished
Verified OK
Resetting Target
flashed: build/win-debug/STM32f407_wuliu.elf
```

**烧录失败处理：**
- 如果连续出现 `CMSIS-DAP command CMD_INFO failed`：
  - 拔插调试器或重新上电
  - 检查 SWD 接线

### 3.4 确认调试器连接 (Windows)

```powershell
# 列出CMSIS-DAP设备
Get-PnpDevice -PresentOnly |
  Where-Object { $_.InstanceId -like "*VID_FAED*" }

# 列出串口
Get-CimInstance Win32_SerialPort |
  Where-Object { $_.Name -like "*CMSIS-DAP*" }
```

## 4. 上电启动流程

### 4.1 主固件 (wuliu) 启动序列

烧录后，观察调试串口 (UART5, 115200) 输出：

```
# BOOT race_chassis_init
# SJ HOMEZERO START ... current=750 time=30 timeout=3000
# SJ HOMEZERO DONE status=0x01
# SJ HOMEZERO CLEAR driver_pos=0 software_pos=0.000
```

以上表示：
1. 固件启动成功
2. 升降电机回零完成（升降已上升到顶部零点）
3. LED1 开始闪烁，表示等待上位机握手

### 4.2 初始化后的硬件状态

- 夹爪：**开爪**
- 置物盘：**位置1** (0°)
- 云台：**0°** (置物架方向)
- 平推：**0** (回收安全位)
- 升降：**0** (顶部安全位，刚完成回零)
- 加热：**关闭**
- LED0：亮；LED1：闪烁

### 4.3 等待握手

主固件此时在 `race_wait_host_ready()` 中循环，LED1 闪烁，等待上位机发送握手帧。

收到 `0xFF 39 38 37 36 35 34 33 32 31 0xFE` ("987654321") 后，握手完成。

然后等待物理开关 (PC9) 从高变低（开关释放），比赛流程正式开始。

## 5. 第一次硬件验证

**强烈建议**首次使用时先烧录 `motor_test` 固件，按以下顺序逐项验证。

调试口：COM11 (或其他分配端口), 115200, 8N1

### 5.1 验证清单

#### 步骤1: 基本连通性

```
STATUS          # 应回复固件状态信息
IMU             # 应回复当前 IMU 角度值
SERVO           # 查看3个舵机的当前PWM值
```

#### 步骤2: 夹爪验证

```
ZH 50           # 开爪 (张开)
ZH 25           # 合爪 (闭合)
ZH 50           # 开爪
```

#### 步骤3: 置物盘验证

```
PT 0            # 位置1
PT 135          # 位置2 (旋转1/3圈)
PT 270          # 位置3 (旋转2/3圈)
PT 0            # 回到位置1
```

#### 步骤4: 云台验证

```
YT 0            # 置物架方向
YT 90           # 右环方向
YT 120          # 中心环方向
YT 150          # 左环方向
YT 0            # 回到置物架方向
```

#### 步骤5: 平推验证（**关键，注意方向！**）

```
PUSH EN         # 使能平推
PUSH ZERO       # 标定当前为零点
PUSH 5 400 60   # 小幅度前推
PUSH 0 400 60   # 回零
PUSH -5 400 60  # 如果上面方向反了，试试这个
PUSH STOP       # 急停
```

> **警告：** 如果平推方向反了（向外推而不是向内收），立即发 `PUSH STOP`，然后断电。修改配置后重新测试。

#### 步骤6: 平推归零

```
PUSH HOME       # 先确认方向正确
# 观察物理运动：应朝0位回收
# 如果方向反了：立即 PUSH HSTOP → 断电 → 修改方向配置
```

#### 步骤7: 升降验证

```
SJ EN           # 使能升降
SJ ZERO         # 标定当前为零点
SJ 5 400 60     # 小幅度测试
SJ 0 400 60     # 回零
SJ STOP         # 急停
```

> **警告：** 同样观察升降方向，反向立即停止。

#### 步骤8: 升降归零

```
SJ HOMEZERO     # 碰撞回零（升降前往顶部）
# 观察日志：# SJ HOMEZERO DONE
SJ READ         # 确认 pos_pul=0
```

#### 步骤9: 底盘电机验证

```
RESET           # 恢复默认状态
ACC 160         # 设置加速度
# 依次测试每个轮子
1               # (需要calib模块支持，详见chassis_calib.c)
```

#### 步骤10: 完整动作组回归测试

```
ACT STOP        # 急停
ACT SAFE        # 安全姿态
ACT OPEN        # 开爪
ACT CLOSE       # 合爪
ACT OPEN        # 开爪
ACT RACK        # 置物架抓取准备位
ACT PICK 1      # 工位1抓取测试
ACT OPEN        # 释放
ACT SAFE        # 安全姿态
```

### 5.2 平推/升降标定值记录

实测完成后，用实际值替换 `motor_ack_test.c` 中的默认值：

| 参数 | 文件位置 | 说明 |
|------|----------|------|
| `ACT_X_RACK` | 约第83行 | 平推抓取伸出距离 |
| `ACT_X_PLACE` | 约第84行 | 平推放置伸出距离 |
| `ACT_X_SAFE` | 约第87行 | 平推安全回收位 |
| `ACT_H_RACK` | 约第85行 | 升降抓取高度 |
| `ACT_H_PLACE` | 约第86行 | 升降放置高度 |
| `ACT_H_TRANSFER` | 约第87行 | 升降转移高度 |
| `ACT_H_SAFE` | 约第88行 | 升降安全高度 |
| `ACT_HEAT_COMPARE` | 约第89行 | 加热PWM值 |

## 7. 操控机器人

### 7.1 正常比赛流程

```
完整流程 (全自动):
1. 上位机启动 → 发送握手
2. STM32 收到握手 → 等待开关释放
3. 开关释放 → 自动执行 race_task_run()
4. 各阶段串口命令自动下发到上位机
5. 上位机执行视觉任务后返回结果
6. STM32 根据结果执行运动
7. 全部任务完成 → LED慢闪
```

### 7.2 手动操控 (debug/motor_test固件)

#### 底盘控制

```
# 速度环模式
ACC 160                    # 设置加速度 (0~255)
status                     # 查看当前参数

# PID姿态控制
SET P:1.1 I:0 D:0         # 设置PID参数
LLM ON 0 90               # 原地转到90度 (低功率模式)
LLM OFF                   # 停止

# 手动移动
# 需要calib模块支持: 字符 'V' 前进, 'W' 旋转, 'X'/'Y' 位置移动
```

#### 串口屏显示

比赛时串口屏(USART6)显示任务序列：
```
t0.txt="132+312 "     # 任务码显示
```

### 7.3 通信自检工具

## 8. 动作微调指南

### 8.1 调整流程

```
1. 烧录 motor_test 固件
2. 逐项测试，找到最佳值
3. 记录到代码中
4. 重新构建 + 烧录
5. 用 ACT 命令验证动作链
6. 确认无误后，将值同步到主固件 race_task.c
7. 构建主固件 → 比赛
```

### 8.2 平推位置微调

**设置场景：** 平推伸出去抓取物块的位置

1. 先用 `PUSH 50 200 20` 伸出到当前估计位置
2. 目视判断距离合适与否
3. 微调：
   ```
   PUSH 52 200 20   # 再伸一点
   PUSH 48 200 20   # 收一点
   ```
4. 找到合适位置后在代码中更新：
   - `race_task.c` 第21行：`ACT_X_RACK 50.0f` → 改为你的值
   - `motor_ack_test.c` 第83行：`ACT_X_RACK 50.0f`

**当前标定值：**

| 用途 | 值 | 说明 |
|------|----|------|
| 安全回收位 | 0 | 最内侧 |
| 放置伸出位 | 10 | 放置物块 |
| 抓取伸出位 | 50 | 取物块 |
| 最大限制 | 65 | 超过会卡住 |

### 8.3 升降高度微调

```
# 查看当前位置
SJ

# 测试高度
SJ 10 600 80     # 转移高度
SJ 60 600 80     # 抓取/放置高度
SJ 0 600 80      # 顶部安全位

# 注意: 0 是上电回零后的顶部零点
```

**当前标定值：**

| 用途 | 值 | 说明 |
|------|----|------|
| 安全上位 | 0 | 最上面，回零位置 |
| 转移高度 | 10 | 移动时抬起来 |
| 抓取/放置高度 | 60 | 放下去操作物块 |

### 8.4 云台角度微调

```
YT 0             # 置物架方向
YT 90            # 右环 → 如果没对准，微调：
YT 92            # 调大
YT 88            # 调小
```

**当前角度映射：**

| 环 | code | 角度 | 说明 |
|----|------|------|------|
| 右环 | 1 | 90° | 右边第一个环 |
| 中心环 | 2 | 120° | 正中心环 |
| 左环 | 3 | 150° | 左边第一个环 |

**微调方法：**
在 `race_task.c` 修改：
```c
#define YT_RIGHT_RING_DEG   90.0f   // 改为你的实际值
#define YT_CENTER_RING_DEG  120.0f
#define YT_LEFT_RING_DEG    150.0f
```

### 8.5 夹爪开合微调

```
# 查看当前
SERVO

# 开爪微调 (50°是默认开爪角度)
ZH 48            # 小一点
ZH 52            # 大一点

# 合爪微调 (25°是默认合爪角度)
ZH 23            # 紧一点
ZH 27            # 松一点
```

在代码中修改：
```c
#define ZHUASHOU_CLOSE_DEG 25.0f  // 合爪角度
#define ZHUASHOU_OPEN_DEG  50.0f  // 开爪角度
```

### 8.6 PID姿态参数微调

**场景：** 机器人原地转不到位、过冲、或震荡

**调试流程（motor_test固件）：**
```
LLM ON 0 90      # 原地转到90度
# 观察运动：到位快不快？过不过冲？晃不晃？

SET P:1.5 I:0 D:0.5   # 调整参数
LLM ON 0 90           # 重新测试
LLM OFF               # 停止
```

**5种PID profile 对应关系：**
| Profile | 比赛中的用途 | kp | ki | kd | 特点 |
|---------|-------------|----|----|-----|------|
| 0 (TRANSIT) | 大角度转场 (0→90, etc.) | 2.0 | 0 | 0.8 | 快速响应 |
| 1 (LOW_OUTPUT) | 低功率运动 | 3.3 | 0 | 1.8 | 限输出30 |
| 3 (SETTLE_KI_LOW) | 稳态微调 | 2.0 | 0.05 | 0.4 | 有积分 |
| 4 (SETTLE_KI_HIGH) | 精确定位 | 2.0 | 0.07 | 0.4 | 较大积分 |

修改位置：`race_chassis.c` 第900-930行 `PID_move()` 函数。

### 8.7 底盘速度/加速度微调

```
ACC 160          # 速度环加速度 (0~255)
```

`race_task.c` 中各 `car_move1()` / `car_move_distance()` 调用中：
```c
car_move1(0.0f, -530.0f, 150, 200);
//          x     y     加速度 速度
```

- 加速度 `a_in`: 越小越平滑但越慢 (70~230)

## 9. 视觉参数微调指南

### 9.1 颜色阈值微调

所有视觉函数的颜色阈值都是 **HSV色彩空间**：

```python
# 红色 (双阈值, 因为HSV中红色跨0度)
'red': {
    'lower1': [0, 100, 100], 'upper1': [10, 255, 255],    # 低H范围
    'lower2': [160, 100, 100], 'upper2': [180, 255, 255]  # 高H范围
}
# 绿色
'green': {'lower': [35, 40, 40], 'upper': [89, 255, 255]}
# 蓝色
'blue': {'lower': [90, 60, 60], 'upper': [140, 255, 255]}
```

**微调方法：**
1. 收集比赛场地的实际物块照片
2. 用 HSV 取色工具获取实际HSV值
3. 调宽阈值范围以应对光照变化
4. 在 `host_main.py` 各函数中修改对应阈值

**阈值含义：**
- `H` (色相): 红≈0/180, 绿≈60, 蓝≈120
- `S` (饱和度): 越高颜色越纯, 降低下限适应暗光
- `V` (亮度): 越高越亮, 降低下限适应暗光

### 9.2 霍夫圆检测参数微调

在 `host_main.py` 各视觉函数中：

```python
circles = cv2.HoughCircles(
    gray, cv2.HOUGH_GRADIENT,
    dp=1,              # 分辨率比 (一般=1)
    minDist=30,         # 两圆最小间距 (加大=减少误检)
    param1=50,          # Canny高阈值 (降低=检测更多边缘)
    param2=30,          # 圆心检测阈值 (降低=更多圆, 提高=更严格)
    minRadius=35,       # 最小半径 (px)
    maxRadius=45        # 最大半径 (px)
)
```

| 场景 | minRadius | maxRadius | 说明 |
|------|-----------|-----------|------|
| 物块 (640×480) | 35 | 45 | 近处物块 |
| 色环粗定位 (640×480) | 35 | 38 | 地面色环 |
| 色环精定位 (1920×1080) | 160 | 165 | 放大后的色环 |
| 码垛粗定位 (640×480) | 20 | 27 | 小物块 |

## 10. 常见故障排查

### 10.1 上电无响应

**症状：** 调试串口无输出
- 检查板子供电
- 检查烧录是否成功
- 检查串口线是否正确 (UART5: PC12/PD2)

### 10.2 升降回零失败

**症状：** 日志显示 `# SJ HOMEZERO FAIL` 或 `TIMEOUT`

```
# 可能原因和解决方法：
1. 回零方向反了 → 断电, 修改 homezero 方向参数
2. 堵转电流阈值太低 → 调高 ZDT_HOME_SHENGJIANG_CURRENT_MA
3. 堵转检测时间太短 → 调高 ZDT_HOME_SHENGJIANG_TIME_MS
4. 机械卡住 → 检查机械结构
```

**手动排查 (motor_test固件)：**
```
SJ EN
SJ HCFG 1          # 查看当前配置
SJ HCFG 1 600 40   # 修改参数
SJ READ            # 查看当前状态
SJ HSTAT           # 查看回零状态
SJ HOME            # 再次触发
SJ HSTOP           # 中断(如果出问题)
```

### 10.3 CAN通信异常

**症状：** 电机不运动，或命令返回错误

```
# 排查步骤:
1. 检查CAN总线终端电阻 (应有120Ω)
2. 检查每个电机驱动的地址是否正确
3. 用 motor_test 固件逐个测试电机
4. 检查CAN线是否松动
```

### 10.4 上位机通信不通

**症状：** STM32一直等握手，上位机日志无异常

```
# STM32侧:
- LED1闪烁表示在等待握手
- 检查 USART1 接线 (PA9/PA10)
- 检查波特率是否匹配 (115200)

# 上位机侧:
- 检查串口设备是否存在: ls /dev/tty*
- 检查环境变量 GCS_HOST_SERIAL
- 用 host_probe.ps1 或 host_task_probe.py 手动测试

# 逐级排查:
1. 用USB转串口接电脑 → 用串口助手发 "987654321" → STM32应有响应
2. 上位机侧手动发握手: python3 host_task_probe.py --port COMx --send "987654321"
```

### 10.5 视觉检测失败 (返回 "000000004")

- 检查摄像头是否正确连接
- 检查光照是否太暗/太亮
- 调整颜色阈值 (HSV范围)
- 检查摄像头是否对焦到目标距离
- 用预览模式观察: `python3 host_main.py --ring --dry-run-serial`

### 10.6 舵机不动或抖动

- 检查舵机独立供电是否正常
- PWM值范围 500~2500，超出不会动
- 如果抖动：可能是供电不足或信号干扰
- 用 `SERVO` 命令确认当前PWM值

### 10.7 底盘走不直

- 检查麦克纳姆轮安装方向
- 检查4个电机的编码器脉冲/毫米换算系数 (`x1`/`y1`)
- 调整 `chassis_calib.c` 中的系数

### 10.8 紧急停止

任何时候，在调试串口输入：
```
ACT STOP         # (motor_test固件)
PUSH STOP        # 停止平推
SJ STOP          # 停止升降
RESET            # 停止所有运动，恢复默认状态
```

物理断电永远是最可靠的急停方式。
