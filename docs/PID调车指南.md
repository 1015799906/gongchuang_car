# PID 调车全程详解

> 从上车到记录完参数，每一步都写清楚。

---

## 零、调之前必须确认

输入 `STATUS`，确认这三件事：

```
# MOTOR TEST Ready mode=MANUAL ...
```
- mode 必须是 MANUAL（不是 LLM）
- yaw 值晃动车子会变 → IMU 正常工作
- 车子放平地上，不要垫歪了

如果 IMU 数据不全，先敲 `IMU` 再敲 `IMUREAD` 等几秒，把 IMU 数据喂足。

---

## 一、理解你在调什么

你调的是**角度环**。简单说：

```
你说 "转到 90°"
  → IMU 看现在是 -10°
  → PID 算出差了 100°，输出角速度 25（最大）
  → 四个轮子按这个角速度转
  → 转到 85° 时，差只有 5°，输出变小，减速
  → 转到 90° 时，差为 0，输出 0，停下
```

PID 三个参数各管什么：

| 参数 | 管什么 | 太小的表现 | 太大的表现 |
|------|--------|-----------|-----------|
| **P** | 转弯力度 | 转得慢，到不了目标 | 冲过头，来回晃 |
| **D** | 刹车力度 | 到位了刹不住，过冲 | 转得肉，慢吞吞 |
| **I** | 消除残差 | 停住后角度慢慢漂走 | 来回晃，停不稳 |

---

## 二、第1步：纯P，找震荡边界

**目的：** 找到 P 多大时车子开始来回晃。

每次改完参数，`LLM ON 0 90` 测一次，`LLM OFF` 停，观察运动。

```
(1) SET P:0.3 I:0 D:0
    LLM ON 0 90        → 车转得很慢，还没到 90° 就停了 → P 太小

(2) SET P:0.5 I:0 D:0
    LLM ON 0 90        → 还是慢，但能到了

(3) SET P:0.8 I:0 D:0
    LLM ON 0 90        → 速度快了，有一点点过冲

(4) SET P:1.2 I:0 D:0
    LLM ON 0 90        → 过冲明显，转过了又弹回来一点

(5) SET P:1.6 I:0 D:0
    LLM ON 0 90        → 冲过头 → 弹回来 → 又冲过头 → 来回摆三四次
                       → 这就是震荡了！
```

**记下震荡边界的 P = 1.6**（每台车不一样，这是例子）

---

## 三、第2步：最佳 P = 震荡界 × 0.6

```
SET P:1.0 I:0 D:0       ← 1.6 × 0.6 ≈ 1.0
LLM ON 0 90
```

**期望：** 能快速转到 90°，有一点过冲（超 5° 左右），然后停住。如果还是过冲太多，再降一点 P（比如 0.8）。

```
LLM ON 0 -90            ← 反方向也测一次
LLM ON 0 180            ← 大角度测一次
LLM OFF
```

**记下最佳 P = _____**

---

## 四、第3步：加 D 消过冲

保持 P 不变，从小的 D 开始加：

```
(1) SET P:1.0 I:0 D:0.2
    LLM ON 0 90        → 过冲比刚才小了一点

(2) SET P:1.0 I:0 D:0.4
    LLM ON 0 90        → 几乎不过冲了，到位干净

(3) SET P:1.0 I:0 D:0.6
    LLM ON 0 90        → 没有过冲，但转得有点慢了 → D 有点大了

(4) SET P:1.0 I:0 D:0.4
    LLM ON 0 90        → 回到刚才最好的 D
    LLM ON 0 -90       → 反方向确认
    LLM ON 0 180       → 大角度确认
    LLM ON 0 45        → 小角度确认
    LLM OFF
```

**记下最佳 kp = _____, kd = _____**

---

## 五、第4步：加 I 消残差（可选）

纯 PD 停住后，角度可能会慢慢漂走一两度，这就是残差。

```
SET P:1.0 I:0.01 D:0.4    ← 加一点点 I
LLM ON 0 90
# 观察到位后角度是否稳定
LLM OFF

SET P:1.0 I:0.03 D:0.4    ← 还不够再加一点
LLM ON 0 90
LLM OFF
```

**如果来回晃 → I 太大了，减回去。**
**如果稳定不漂 → 这个 I 够了。**

很多时候 I=0 就够了，不一定非要加。

---

## 六、第5步：确认最终参数

```
STATUS
```

串口返回类似：
```
# MOTOR TEST Ready mode=MANUAL ... pid=1.000,0.010,0.400
```

**记下最终参数：kp = _____, ki = _____, kd = _____**

---

## 七、第6步：大角度全方向验证

最后绕一圈，确保所有方向都正常：

```
LLM ON 0 90        ← 右转 90°
LLM OFF
LLM ON 0 -90       ← 左转 90°
LLM OFF
LLM ON 0 180       ← 右转 180°
LLM OFF
LLM ON 0 -180      ← 左转 180°
LLM OFF
LLM ON 0 360       ← 转一整圈
LLM OFF
LLM ON 40 90       ← 边前进边右转（如果场地允许）
LLM OFF
```

每次 `LLM ON` 之间必须 `LLM OFF` 停一下，不然 PID 状态乱。

## 八、怎么读串口数据判断好坏

`LLM ON 0 90` 开始后，串口每 50ms 输出一行：

```
时间戳, target, feedback, output, error, kp, ki, kd
5000,  79.200, -10.822, 25.000, 90.022, 1.000, 0.010, 0.400   ← 刚开始，输出被限幅25夹住了
5050,  79.200,   5.134, 25.000, 74.066, ...
5100,  79.200,  18.544, 25.000, 60.656, ...
5150,  79.200,  30.271, 25.000, 48.929, ...
5200,  79.200,  40.557, 25.000, 38.643, ...
5250,  79.200,  49.612, 25.000, 29.588, ...
5300,  79.200,  57.611, 21.589, 21.589, ...   ← error减小，output开始下降
5350,  79.200,  64.697, 14.503, 14.503, ...
5400,  79.200,  70.987,  8.213,  8.213, ...
5450,  79.200,  75.423,  3.777,  3.777, ...   ← 快到了，减速
5500,  79.200,  78.112,  1.088,  1.088, ...
5550,  79.200,  79.089,  0.111,  0.111, ...
5600,  79.200,  79.200,  0.000,  0.000, ...   ← 到位
5650,  79.200,  79.104,  0.096,  0.096, ...   ← 微微回调
5700,  79.200,  79.200,  0.000,  0.000, ...   ← 稳住
```

**好的图线：** error 从 90 平滑降到 0，没有正负反复跳，output 平滑下降。
**坏的图线：** error 一会儿正一会儿负 → 震荡 → P 太大或 D 太小。

## 九、常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 转不动，output 一直 0 | IMU 没数据 | `IMUREAD` 等几秒 |
| 转了一下就停了，没到位 | P 太小 | 加大 P |
| 冲过头又来回来回转 | P 太大或 D 太小 | 降 P 或加 D |
| 到位后又慢慢漂走 | 有稳态误差 | 加一点 I（0.01~0.03） |
| 转得太慢 | maxOutput 限 25 | 这个上限不能改，比赛版是 180，可以调大 P 来间接提速 |
| `LLM ON` 报 IMU data incomplete | IMU 数据不够 | 先执行 `IMUREAD`，等几秒 |
