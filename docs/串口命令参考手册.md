# motor_test 串口命令参考手册

> 烧录 motor_test 固件后，通过 UART5（PC12/PD2，115200-8N1）发送以下命令控制机器人。
> 每行一条命令，以回车（`\n`）结束。不区分大小写（部分命令除外）。

---

## 一、基本状态查询

### STATUS
查看当前全部状态。
```
STATUS
```
返回：舵机PWM值、升降/平推软件位置、IMU角度、PID参数、加速度等。

### SERVO
查看三个舵机的当前 PWM 值。
```
SERVO
```
返回：`CH2=<夹爪> CH3=<置物盘> CH4=<云台>`

直接设置PWM值：
```
SERVO 2 862       # 设夹爪PWM=862
SERVO 3 1500      # 设置物盘PWM=1500
SERVO 4 500       # 设云台PWM=500
```

### IMU
查看 IMU 角度。
```
IMU
```
返回：Roll/Pitch/Yaw 三个欧拉角（°）。

### ENC
读取四个底盘电机的编码器位置。
```
ENC
```

### RESET
停止所有运动，恢复默认 PID 和加速度参数。
```
RESET
```

## 二、舵机控制

### ZH — 夹爪
```
ZH 50             # 开爪（默认50°）
ZH 25             # 合爪（默认25°）
```
参数范围：0 ~ 270°

### PT — 置物盘
```
PT 0              # 工位1（0°）
PT 135            # 工位2（135°）
PT 270            # 工位3（270°）
```
参数范围：0 ~ 270°

### YT — 云台
```
YT 0              # 置物架方向（0°）
YT 90             # 右环方向
YT 120            # 中心环方向
YT 150            # 左环方向
```
参数范围：0 ~ 360°

## 三、升降电机 (SJ)

### SJ — 查看状态
```
SJ
SJ?
SJ READ           # 读取驱动器位置/速度/状态
```

### SJ EN / SJ DIS — 使能/失能
```
SJ EN             # 使能升降电机（地址5）
SJ DIS            # 失能
```

### SJ 位置控制
```
格式: SJ <目标位置> <速度> <加速度>

SJ 10 600 80      # 降到10mm，速度600，加速度80
SJ 33 1000 120    # 降到33mm
SJ 60 600 80      # 降到60mm（放置高度）
SJ 0 600 80       # 升回0mm（顶部零点）
```
- 目标位置：0 ~ 135 mm
- 速度：建议 400 ~ 1000
- 加速度：建议 60 ~ 120

### SJ STOP — 急停
```
SJ STOP           # 中止回零 + 连续3次立即停止
```

### SJ ZERO — 标定零点
```
SJ ZERO           # 把当前物理位置标记为软件0位（不驱动电机）
SJ SET 60         # 把当前物理位置标记为软件60位
```
> 注意：`SJ ZERO` 只是改软件位置变量，不驱动物理电机。

### SJ CLEAR — 清零
```
SJ CLEAR          # 驱动器位置/误差/脉冲清零 + 软件位置置0
```
> 仅在确认升降已在顶部0位后使用。

### SJ UNSTALL — 解除堵转
```
SJ UNSTALL        # 解除地址5堵转保护
```

---

### SJ HOMEZERO — 碰撞回零（最常用）

让升降向上运动，碰到顶部机械限位后自动停止并清零。

```
SJ HOMEZERO                          # 默认参数：dir=1, current=600mA, time=40ms, timeout=10000ms
SJ HOMEZERO 1                        # 指定方向(0或1)
SJ HOMEZERO 1 600 40                 # 方向1, 碰撞电流600mA, 持续时间40ms
SJ HOMEZERO 1 600 40 10000           # 方向1, 电流600mA, 40ms, 超时10s
```

**参数约束：**
| 参数 | 范围 | 说明 |
|------|------|------|
| dir | 0 或 1 | 回零运动方向 |
| current_ma | 400 ~ 3000 | 碰撞判定电流阈值（越小越敏感） |
| time_ms | 20 ~ 200 | 碰撞持续时间阈值 |
| timeout_ms | 1000 ~ 30000 | 总超时 |

### SJ HCFG — 配置回零参数（不触发）
```
SJ HCFG 0          # 方向CW，默认电流600mA/40ms
SJ HCFG 1          # 方向CCW
SJ HCFG 1 400 20   # 方向CCW，400mA，20ms（更敏感）
SJ HCFG 0 800 50   # 方向CW，800mA，50ms（更不敏感）
```

### SJ HSTAT — 读回零参数和状态
```
SJ HSTAT           # 读取地址5的回零配置(0x22)和回零状态(0x3B)
```

### SJ HSTOP — 中止回零
```
SJ HSTOP           # 中断回零 + 连续3次立即停止
```

### SJ HOME / SJ HOME3
```
SJ HOME            # 触发多圈无限位碰撞回零(mode=2)
SJ HOME3           # 触发多圈有限位开关回零(mode=3)
```

### SJ UPZERO — 限时轻顶归零
```
SJ UP 200 30 20    # 向上(dir=1)轻顶200ms后停止，不清零
SJ UPZERO 500 30 20  # 向上轻顶500ms后停止 + 清零
```

## 四、平推电机 (PUSH)

### PUSH — 查看状态
```
PUSH
PUSH?
PUSH READ          # 读取驱动器位置/速度/状态
```

### PUSH EN / PUSH DIS — 使能/失能
```
PUSH EN            # 使能平推电机（地址6）
PUSH DIS           # 失能
```

### PUSH 位置控制
```
格式: PUSH <目标位置> <速度> <加速度>

PUSH 5 400 60      # 前推5mm
PUSH -5 400 60     # 后退5mm
PUSH 50 200 20     # 抓取伸出位
PUSH 10 200 20     # 放置位
PUSH 0 200 20      # 回收零点
```
- 目标位置：-20 ~ 65 mm
- 速度：建议 200 ~ 600
- 加速度：建议 20 ~ 80

### PUSH STOP — 急停
```
PUSH STOP          # 连续3次立即停止
```

### PUSH ZERO — 标定零点
```
PUSH ZERO          # 软件位置置0（不驱动电机）
PUSH SET 50        # 标记软件位置=50
```

### PUSH CLEAR — 清零
```
PUSH CLEAR         # 驱动器位置清零 + 软件位置置0
```

### PUSH HOMEZERO — 碰撞回零
```
PUSH HOMEZERO                       # 默认：dir=0, current=800mA, time=60ms, timeout=10000ms
PUSH HOMEZERO 0 800 60              # 指定方向/电流/时间
PUSH HOMEZERO 0 800 60 10000        # 指定方向/电流/时间/超时
```

### PUSH HCFG — 配置回零参数
```
PUSH HCFG 0        # 方向CW，默认800mA/60ms
PUSH HCFG 1        # 方向CCW
PUSH HCFG 1 600 40 # 方向CCW，600mA，40ms
```

### PUSH HSTAT / HSTOP / HOME / HOME3 / UNSTALL
```
PUSH HSTAT         # 读回零参数和状态
PUSH HSTOP         # 中止回零
PUSH HOME          # 触发碰撞回零(mode=2)
PUSH HOME3         # 触发限位开关回零(mode=3)
PUSH UNSTALL       # 解除堵转
```

## 五、动作组 (ACT)

动作组命令会**先执行一次升降 HOMEZERO**，再执行动作链。

### ACT SAFE / ACT RESET — 安全姿态
```
ACT SAFE           # 开爪 + 置物盘1 + 平推0 + 升降0 + 云台0 + 关加热
ACT RESET          # 同上
```

### ACT OPEN / ACT CLOSE — 夹爪
```
ACT OPEN           # 开爪
ACT CLOSE          # 合爪
```

### ACT STOP — 全部急停
```
ACT STOP           # 底盘停 + 平推开降回零 + 各连续3次停止 + 关加热
```

### ACT ZERO — 执行器归零
```
ACT ZERO           # 平推软件标0 + 升降HOMEZERO后清零
```

### ACT RACK — 置物架抓取准备位
```
ACT RACK           # 升降HOMEZERO → 开爪 → 置物盘1 → 平推抓取位 + 升降抓取高度
```

### ACT PICK 1/2/3 — 单工位抓取
```
ACT PICK 1         # 置物盘切到工位1 → 平推伸出 → 升降降到抓取高度 → 合爪
ACT PICK 2         # 工位2
ACT PICK 3         # 工位3
```

### ACT PLATFORM 1/2/3 — 切换置物盘
```
ACT PLATFORM 1     # 等价 PT 0
ACT PLATFORM 2     # 等价 PT 135
ACT PLATFORM 3     # 等价 PT 270
```

### ACT HEAT — 加热控制
```
ACT HEAT ON        # 开加热（PWM=300）
ACT HEAT OFF       # 关加热
ACT HEAT 500       # 直接设加热PWM=500
```
PWM 范围：0 ~ 1999

### ACT ROUND3 — 三工位完整动作链
```
ACT ROUND3         # 升降HOMEZERO → 工位1/2/3各抓一次 → 右/中/左环各放一次
```

### ACT FANG — 放置
```
ACT FANG R         # 放到右环（红色位置）
ACT FANG G         # 放到中心环（绿色位置）
ACT FANG B         # 放到左环（蓝色位置）
```

### ACT FANGMD — 码垛放置
```
ACT FANGMD R       # 码垛放到右环位置
ACT FANGMD G       # 码垛放到中心环
ACT FANGMD B       # 码垛放到左环
```

### ACT NA — 色环区取回
```
ACT NA R           # 从右环位取物块并带回置物架
ACT NA G           # 从中心环位取回
ACT NA B           # 从左环位取回
```

### ACT YTNA — 圆台完整取回
```
ACT YTNA R         # 圆台红色工位：完整抓取+取回
ACT YTNA G
ACT YTNA B
```

### ACT NA1 — 圆台预置位（只开爪）
```
ACT NA1 R          # 转到红色工位，开爪等待
ACT NA1 G
ACT NA1 B
```

### ACT NA2 — 圆台夹取带回
```
ACT NA2 R          # 转到红色工位，合爪夹取，带回置物架
ACT NA2 G
ACT NA2 B
```

### ACT POSE — 手动三联定位
```
ACT POSE 50 60 0     # 平推50mm + 升降60mm + 云台0°
ACT POSE 10 60 90    # 右环放置姿态
ACT POSE 10 60 120   # 中心环放置姿态
ACT POSE 10 60 150   # 左环放置姿态
```

## 六、底盘调参

### PID 参数设置
```
SET P:1.5 I:0 D:0.5     # 设置 PID 参数
PID P:1.5 I:0 D:0.5     # 同上（PID 和 SET 等价）
```

### ACC — 加速度
```
ACC 160                  # 设置速度环加速度（0~255）
```

### LLM — 原地旋转姿态调参
```
LLM ON 0 90              # 以速度0，目标Yaw=90°，原地旋转调参
LLM ON 0 -90             # 目标-90°
LLM OFF                  # 停止调参运动
```
`LLM ON` 格式：`LLM ON <驱动速度> <目标Yaw°>`

### WHEEL — 单电机速度测试
```
WHEEL 1 100              # 电机1以速度100转
WHEEL 2 200              # 电机2
WHEEL 3 -100             # 电机3反向
WHEEL 4 0                # 电机4停
```
速度范围：-300 ~ 300

### MOVE — 底盘速度矢量
```
MOVE 0 100 0             # 前进 (vx=0, vy=100, w=0)
MOVE 100 0 0             # 右移
MOVE 0 0 50              # 逆时针旋转
MOVE -50 0 0             # 左移
```
格式：`MOVE <vx> <vy> <w>`，速度范围：-300 ~ 300

### PULSE / PULSE1 — 位置脉冲测试
```
PULSE 1 1000             # 电机1走1000脉冲
PULSE1 2 500             # 电机2走500脉冲
```

## 七、完整交互示例

### 示例1：上电后首次调车
```
STATUS                   # 查看初始状态
RESET                    # 确保安全
ACT SAFE                 # 全部回安全位
SERVO                    # 查看舵机状态
SJ HOMEZERO              # 升降回零
SJ READ                  # 确认回零成功
PUSH ZERO                # 平推标零
PUSH 5 400 60            # 平推微测
PUSH 0 400 60            # 回收
```

### 示例2：调平推抓取位
```
PUSH ZERO
PUSH 50 200 20           # 伸到当前估计的抓取位
# 观察位置是否合适
PUSH 52 200 20           # 不够再伸
PUSH 48 200 20           # 太远收一点
# 找到最佳值后记录
```

### 示例3：调云台角度
```
ACT POSE 0 10 90         # 到右环测试位
YT 88                    # 微调
YT 92
YT 90                    # 最佳值
```

### 示例4：调PID
```
LLM ON 0 90              # 原地转90°
# 观察到位情况和过冲
SET P:1.5 I:0 D:0.5      # 调参
LLM ON 0 90              # 重测
LLM OFF                  # 停止
```

### 示例5：危险情况处理
```
# 如果任何电机失控：
SJ STOP                  # 停升降
PUSH STOP                # 停平推
ACT STOP                 # 全部急停
# 最可靠：直接拔电源
```

## 八、默认标定值速查

| 项目 | 默认值 |
|------|--------|
| 夹爪开/合 | 50° / 25° |
| 置物盘三工位 | 0° / 135° / 270° |
| 云台角度 | 0(置物架) / 90(右环) / 120(中心环) / 150(左环) |
| 平推位置 | 0(回收) / 10(放置) / 50(抓取) / 65(最大) |
| 升降位置 | 0(顶部) / 10(转移) / 60(放置/抓取) / 135(最大) |
| 加热PWM | 300 |
| 默认加速度 | 160 |
| PID kp/ki/kd | 1.1 / 0 / 0 |
