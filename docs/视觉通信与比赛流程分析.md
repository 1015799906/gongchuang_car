# 视觉通信与比赛流程分析

---

## 一、通信架构

```
RDK X5 (上位机)                    STM32F407 (下位机)              外设
   │                                    │                          │
   │── USART1 (PA9/PA10) ──────────────│                          │
   │   帧协议: 0xFF+9字节+0xFE          │                          │
   │   单字节命令 ←────────────────────│                          │
   │                                    │                          │
   │                                    │── USART6 (PC6/PC7) ──── HMI串口屏
   │                                    │── CAN1 ──────────────── 6个电机
   │                                    │── TIM2 ──────────────── 舵机×3
   │                                    │── USART2 ────────────── IMU模块
   │                                    │── UART5 ─────────────── 调试口(PC)
```

**物理层**：
- 上位机协议口：USART1 (PA9/PA10)，9600波特率
- 调试口：UART5 (PC12/PD2)，9600波特率
- HMI屏幕口：USART6 (PC6/PC7)，9600波特率

## 二、协议帧格式

### 上位机 → STM32：11字节帧

```
┌──────┬──────────────────────────┬──────┐
│ 0xFF │     9字节 ASCII 载荷      │ 0xFE │
└──────┴──────────────────────────┴──────┘
```

| 载荷格式 | 含义 | 示例 |
|----------|------|------|
| `987654321` | 握手帧（上位机启动就绪） | 上位机开机后发 |
| `000000004` | 检测失败/未识别 | 视觉没找到目标 |
| `xxxxyyyyc` | 坐标+颜色 | `09550519001` = x=955, y=519, 红色 |

**坐标帧解析**（以 `09550519001` 为例）：
```
Serial_RxPacket[0]='0'  Serial_RxPacket[4]='0'    ┐
Serial_RxPacket[1]='9'  Serial_RxPacket[5]='5'    │ 四位像素X坐标: 0955
Serial_RxPacket[2]='5'  Serial_RxPacket[6]='1'    │
Serial_RxPacket[3]='5'  Serial_RxPacket[7]='9'    ┘ 四位像素Y坐标: 0519
Serial_RxPacket[8]='1'  → 颜色码 '1'=红
```

**颜色码 (第9字节)**：
| 值 | 含义 |
|----|------|
| `0x31` = '1' | 红色 |
| `0x32` = '2' | 绿色 |
| `0x33` = '3' | 蓝色 |
| `0x34` = '4' | 未识别/重试信号 |

### STM32 → 上位机：单字节命令

| 字节 | 含义 | 发送时机 |
|------|------|---------|
| `0x31` | 触发物块识别 | 比赛开始，车进入物块区 |
| `0x32` | 触发物块精定位 | 车粗到位后，请求精确坐标 |
| `0x33` | 触发圆台颜色识别 | 物块取完，进入圆台区 |
| `0x34` | 触发第二组圆台识别 | 第二轮圆台 |
| `0x35` | 触发第2个物料去圆台 | 圆台阶段中间步骤 |
| `0x36` | 触发第3个物料去圆台 | 圆台阶段中间步骤 |
| `0x37` | 触发色环粗定位 | 进入色环区，请求坐标 |
| `0x38` | 触发色环精定位 | 粗到位后，请求精调坐标 |
| `0x39` | 触发第三轮色环 | 第三轮物料处理 |
| `0x61` | 触发第二轮物块识别 | 第二轮循环 |
| `0x62` | 第二轮圆台触发 | 第二轮圆台 |
| `0x63` | 第二轮圆台触发 | 第二轮圆台 |

上位机看到这些字节后，调用视觉模型拍照识别，返回坐标帧。

## 三、关键函数详解

### 3.1 `wait_send_shumeipai(message, time)`

```c
static void wait_send_shumeipai(uint8_t message, uint16_t time)
```

**阻塞式**：发送一个触发字节给上位机，然后死等上位机返回一帧数据。

流程：
1. 清空接收标志 `Serial_GetRxFlag()`
2. 发送触发字节 `Serial_SendByte(message)` → 上位机收到后拍照识别
3. `while(1)` 轮询 `Serial_GetRxFlag()`，直到收到完整帧
4. 收到后返回，`Serial_RxPacket[]` 里就是上位机的坐标数据

### 3.2 `transfer_position_wukuai(task_choose, distance, color)`

将上位机返回的**像素坐标**转换为**物理移动距离**（物块区）。

```c
// 解析像素坐标
x_origin = (Serial_RxPacket[0..3] 四位十进制数)  // X像素
y_origin = (Serial_RxPacket[4..7] 四位十进制数)  // Y像素

// 减去像素原点偏移
x_origin -= 322.0f;  // task_choose=1
y_origin -= 165.0f;

// 比例尺（非线性，随距离变化）
bilichi = -0.0035f * (distance + 80.0f) + 1.1967f;

// 物理移动距离
direct_x = x_origin * bilichi;
direct_y = y_origin * bilichi;
```

然后根据颜色码调整多物料时的横向偏移 `distance_wukuai(150mm)`：

```
红色物料: 颜色='2'时左偏150, 颜色='3'时左偏300
绿色物料: 颜色='1'时右偏150, 颜色='3'时左偏150
蓝色物料: 颜色='2'时左偏150, 颜色='1'时左偏300
颜色='4'(未识别): direct_y=5, direct_x=-5 (原地小步试探)
```

**注意**：这里的颜色码不是物料自身的颜色，而是物品在平台上的**相对位置**编码。

### 3.3 `transfer_position_sehuan(fenbian_choose, task_num)`

将像素坐标转为物理距离（**色环区**）。

两种分辨率模式：

**模式1 (fenbian_choose=0x01)**：
```c
x_center = 316.0f; y_center = 238.0f;  // 图像中心点
direct_x = (x_origin - x_center) * 1.1805555f;  // 比例因子
direct_y = (y_origin - y_center) * 1.1805555f;
```

**模式2 (fenbian_choose=0x02)**：
```c
// 中心点按颜色不同
红: x_center=955, y_center=519
绿: x_center=955, y_center=519
蓝: x_center=955, y_center=519
direct_x = (x_origin - x_center) * 0.29239766f;
direct_y = (y_origin - y_center) * 0.29239766f;
```

### 3.4 `car_move_distance(dx, dy, speed, acc)`

视觉引导的增量移动。调用 `car_move()` 行驶 `(dx, dy)` 的相对位移。

**用途**：上位机给了坐标后，用这个函数微调到精确位置。

### 3.5 `PID_move(vx, vy, w, timeout, target_angle, mode)`

IMU角度闭环移动。

- `vx, vy, w`: 底盘速度/角速度
- `target_angle`: 目标Yaw角（绝对角度）
- `mode`: 0=仅角度,其它=同时移动+转角度

内部调用 `PID_Calc(&mypid, target_angle, feedback_yaw)` 做角度闭环。

### 3.6 `na(color)` / `fangzhi(color)` / `fangzhi_maduo(color)`

动作函数（参考动作组文档）：
- `na()`: 从货架取物料（抓手合→缩回→放货架→抓手开）
- `fangzhi()`: 放物料到色环（到环前→升高→抓手开）
- `fangzhi_maduo()`: 多物料放置变体
- `yuantai_na()` / `yuantai_na1` / `yuantai_na2`: 圆台取料

### 3.7 `shengjiang_control(target, speed, acc)`

升降电机单轴运动，返回耗时(ms)。用于 `delay_ms1(shengjiang_control(...))` 做阻塞等待。

## 四、比赛完整流程 (race_task_run)

```
┌──────────────────────────────────────────────────────────────────┐
│                     比赛开始 race_task_run()                      │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ① 发0x31 → 收物块颜色序列 → 存入task[0..5]                      │
│     上位机返回9字节，前6位是6个物料的颜色(1/2/3)                  │
│                                                                  │
│  ② 物块平台=1号位，加热开                                        │
│     move_all1: 平推归位(-120)、升降归零                          │
│     car_move1: 后退910mm                                          │
│     move_all1: 平推伸出(40)                                       │
│                                                                  │
│  ③ 发0x32 → 收物块坐标 → transfer_position_wukuai()             │
│     循环: car_move_distance(direct_x, direct_y) 逐物块靠近       │
│     若颜色=4(未识别): 发0x32重试，最多循环                       │
│                                                                  │
│  ④ move_all: 平推伸出(60)                                        │
│     wait_send_shumeipai(0x33) → 收圆台颜色码 ypcode[0..2]       │
│                                                                  │
│  ⑤ 圆台取料:                                                     │
│     平台1 → yuantai_na(ypcode[0])                                │
│     平台2 → yuantai_na1(ypcode[1])                               │
│     发0x35 → wait_packet_98() → yuantai_na2(ypcode[1])          │
│     平台3 → yuantai_na1(ypcode[2])                               │
│     发0x36 → wait_packet_98() → yuantai_na2(ypcode[2])          │
│                                                                  │
│  ⑥ 加热关，离开圆台区                                           │
│     PID_move(-30,0,0,...): 后退30mm                              │
│     car_move1(0,400): 侧移400mm                                  │
│     PID_move(0,0,0, 90°): 转90°                                  │
│     car_move1(0,-1700): 后退1700mm                               │
│     PID_move(0,0,0, -180°): 转180°                               │
│                                                                  │
│  ⑦ 进入色环区（第一轮）                                         │
│     加热开                                                        │
│     循环: 发0x37 → transfer_position_sehuan(mode1) → 靠近       │
│          直到上位机不再返回4(未识别)                              │
│     PID_move: 转-180°                                            │
│     发0x38 → transfer_position_sehuan(mode2) → 精调靠近         │
│     若颜色=4: 原地不动(0,0)，否则 car_move_distance              │
│                                                                  │
│  ⑧ 放置物料到色环:                                              │
│     move_all: 平推归位(-48)、升降归位(33)                        │
│     抓手合                                                       │
│     fangzhi(task[0]): 放红/绿/蓝到对应环                         │
│     shengjiang_control(33): 升降到33                              │
│     fangzhi(task[1])                                             │
│     fangzhi(task[2])                                             │
│     na(task[0/1/2]): 取新物料                                    │
│                                                                  │
│  ⑨ 返回色环区（第二轮），重复类似流程                            │
│     ...                                                          │
│                                                                  │
│  ⑩ 返回色环区（第三轮），fangzhi_maduo() 多用                   │
│     ...                                                          │
│                                                                  │
│  ⑪ 比赛结束                                                     │
│     car_move1(140,1850): 前进1850mm                              │
│     car_move2(-130,0): 侧移-130mm                                │
│     race_finish_stop(): 归位→LED闪烁→死循环                     │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

## 五、如何与视觉配合调试

### 5.1 上位机端需要做的事

1. **接收单字节命令**：监听 USART1，收到一个字节后根据命令码拍照识别。
2. **返回坐标帧**：识别完成后，发送 `0xFF + "xxxxxyyyyc" + 0xFE`。
3. **握手**：上位机启动后发送 `0xFF + "987654321" + 0xFE`。

### 5.2 你需要调的关键参数

#### 比例尺（坐标转换系数）

`transfer_position_wukuai()` 里的 `bilichi` 公式：
```c
bilichi = -0.0035f * (distance + 80.0f) + 1.1967f;
```

`transfer_position_sehuan()` 里的比例因子：
```c
direct = (pixel - center) * 1.1805555f;   // 模式1
direct = (pixel - center) * 0.29239766f;  // 模式2
```

这些系数需要在实地测量后校准。方法：车停在已知位置，视觉给像素坐标，测量实际物理距离，反算比例因子。

#### 像素原点偏移

```c
x_origin -= 322.0f;  // 物块区
y_origin -= 165.0f;
x_origin -= 314.0f;  // 物块区(模式2)
y_origin -= 238.0f;
```

#### 导航路径

`race_task_run()` 里的所有 `car_move1()`、`car_move1()` 的移动距离(m/s)都是硬编码的场地参数，需要根据实际比赛场地尺寸调整。

### 5.3 调试建议

1. **先测通信**：上位机发握手帧 `987654321`，STM32收到后LED闪烁，确认USART1物理没问题。
2. **再测单帧**：手动发一个坐标帧，看 `direct_x/direct_y` 算出来对不对。
3. **分阶段调**：不要一口气跑全流程。把 `race_task_run()` 拆开，单步走 ①→②→③，确认视觉+移动对上了再往下走。

## 六、与 motor_ack_test 的关系

`motor_ack_test.c` 是**调试固件**——用 `MOVE`/`LLM`/`ACT` 等命令手动控制，上电自动进入。

`race_task.c` 是**比赛固件**——调用 `race_task_run()` 自动跑完整流程。

目前 `main.c` 调的是 `motor_ack_test_poll()`（调试模式）。实地跑需要切到比赛模式，在 `main.c` 的 while(1) 里改调 `race_task_run()`，或通过串口命令触发切换。

切换方式取决于你们的设计——可能需要一个专门的编译宏（DEBUG vs RACE），或者在调试固件里加一个 `RACE` 命令来触发比赛流程。
