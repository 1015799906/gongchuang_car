## 1. main.c

**路径:** `STM32f407_wuliu/Core/Src/main.c`

### `static void boot_log(const char *s)`

- **功能:** 启动阶段通过调试串口(DBG_UART = UART5)输出日志字符串。
- **参数:** `s` — 以 `\0` 结尾的字符串。
- **用法:** 仅在 `main()` 启动阶段调用一次，输出 `"# BOOT race_chassis_init\r\n"`。
- **内部实现:** 计算字符串长度，然后调用 `HAL_UART_Transmit` 阻塞发送。

### `void SystemClock_Config(void)`

- **功能:** 配置系统时钟为 168MHz。
  - HSE 8MHz 外部晶振 → PLL ×336 /2 = 168MHz SYSCLK
  - AHB=168MHz, APB1=42MHz, APB2=84MHz
  - Flash等待周期=5, 使能CSS(时钟安全系统)
- **调用时机:** `main()` 中，在 `HAL_Init()` 之后、外设初始化之前。

### `int main(void)`

- **功能:** 固件入口。完整流程:
  1. `HAL_Init()` — 复位外设
  2. `SystemClock_Config()` — 168MHz
  3. 各外设初始化 (CAN/UART/TIM/GPIO)
  4. `host_init()` — 武装上位机接收中断
  5. `race_chassis_init()` — 底盘/执行器初始化
  6. `race_wait_host_ready()` — 等待上位机握手
  7. `race_wait_switch()` — 等待开关释放
  8. 无限循环 `race_task_run()` — 比赛任务

### `void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)`

- **功能:** 串口接收完成中断回调。分发到对应模块：
  - `huart == &HOST_UART` → `host_isr_rx_cplt()` (上位机协议)
  - `huart == &huart2` → `imu_uart2_rx_cplt()` (IMU传感器)
- **调用者:** HAL库中断上下文。

### `void HAL_CAN_RxFifo0MsgPendingCallback(CAN_HandleTypeDef *hcan)`

- **功能:** CAN接收中断回调，将电机反馈帧存入环形缓冲区。
- **调用者:** HAL库中断上下文。
- **调用:** `race_chassis_can_rx_callback(hcan)`

### `void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)`

- **功能:** 定时器周期中断回调。
  - `htim == &htim4` → `race_chassis_tim4_callback()` (50ms PID周期)
- **调用者:** HAL库中断上下文。

### `void Error_Handler(void)`

- **功能:** 严重错误处理。关闭全局中断后死循环。
- **调用者:** 各 HAL 初始化函数在失败时调用。

### `static void race_host_timeout_stop(void)`

- **功能:** 通信超时/失败时的紧急处理。
- **行为:** 停止所有执行器 → 底盘停止 → 死循环闪烁LED1(200ms周期)。
- **调用者:** 所有 `wait_rx_ms()`/`wait_send_shumeipai()` 超时分支。

### `static uint8_t wait_rx_ms(uint32_t time)`

- **功能:** 等待上位机发来数据包，带超时。
- **参数:** `time` — 超时时间(ms)。
- **返回值:** 1 = 超时前收到包, 0 = 超时。
- **内部:** 轮询 `Serial_GetRxFlag()`，有新包立即返回1。

### `static uint8_t wait_send_shumeipai(uint8_t message, uint16_t time)`

- **功能:** 发送一个命令字节给上位机，然后等待回复。
- **参数:** `message` — 命令字节(即视觉命令宏), `time` — 等待超时(ms)。
- **返回值:** 1 = 收到回复, 0 = 超时。
- **内部:** 先清标志 → 发送命令 → 调用 `wait_rx_ms()` 等待。

### `static void wait_packet_98(void)`

- **功能:** 等待上位机回复特定的 "98" 确认包(包首两字节为 '9','8')。
- **超时:** `VISION_WAIT_ACK_MS` (30秒)。
- **用途:** 颜色验证流程中(`VISION_CMD_FIRST_BLOCK_CODE1`/`CODE2` 等)等待确认。
- **超时后:** 调用 `race_host_timeout_stop()`。

### `static void transfer_position_wukuai(uint8_t task_choose, float distance, uint8_t color)`

- **功能:** 将上位机返回的**物块图像坐标**转换为**世界坐标**(mm)。
- **参数:**
  - `task_choose` — 0x01=第一圈, 0x02=第二圈(影响比例尺公式)
  - `distance` — 摄像头距物块距离(影响比例尺)
  - `color` — 目标颜色(用于偏移校正)
- **解析协议:** `Serial_RxPacket[0..3]`=x像素, `[4..7]`=y像素, `[8]`=颜色
- **输出:** 全局变量 `direct_x`, `direct_y`(目标世界坐标mm)。
- **颜色偏移逻辑:**
  - color=2(绿): 红色右偏+150mm, 蓝色左偏-150mm
  - color=1(红): 绿色左偏-150mm, 蓝色左偏-300mm
  - color=3(蓝): 绿色右偏+150mm, 红色右偏+300mm
  - MISS(4): 默认 (5, -5)

### `static void transfer_position_sehuan(uint8_t fenbian_choose, uint8_t task_num)`

- **功能:** 将上位机返回的**色环图像坐标**转换为**世界坐标**(mm)。
- **参数:**
  - `fenbian_choose` — 0x01=粗定位(1/4分辨率), 0x02=精定位(全分辨率)
  - `task_num` — 任务编号(1/2/3)，影响颜色偏移方向
- **粗定位:** 减去中心(316,238)，比例尺 1.1805555
- **精定位:** 减去对应颜色中心(红/绿/蓝各有 x_center/y_center)，比例尺 0.29239766

### `static float yaw_for_code(uint8_t code)`

- **功能:** 将环编码(code)映射为云台角度。
  - code=1 → 90°(右环)
  - code=2 → 120°(中心环)
  - 其他 → 150°(左环)

### `static void act_pose(float ping, float lift, float yaw)`

- **功能:** 三轴联动——同时控制平推、升降、云台运动。
- **参数:** `ping`=平推目标(mm), `lift`=升降目标(mm), `yaw`=云台目标角度(°)。
- **内部:** 调用 `move_all()`。

### `static void act_zero_before_chain(void)`

- **功能:** 动作链前的执行器归零流程:
  1. 停止所有执行器
  2. 平推清零
  3. 升降归零(homezero)
  4. 开爪
  5. 置物盘→位置1
  6. 三轴到安全位(0, 0, 0°)

### `static void act_safe_transfer(void)`

- **功能:** 执行器回到安全转移位(平推0, 升降10, 云台0°)。
- **用途:** 机器人移动时执行器处于收缩状态。

### `static void act_pick_current_platform(void)`

- **功能:** 从当前置物盘工位抓取物块。
- **流程:** 开爪 → 伸到抓取位(50,60,0°) → 合爪 → 抬到转移位(50,10,0°)。

### `static void act_release_to_yaw(float yaw)`

- **功能:** 将物块放置到指定云台角度位置。
- **流程:** 伸到放置位(10,10,yaw) → 降到放置高度(10,60,yaw) → 开爪 → 抬起(10,10,yaw) → 安全转移。

### `static void act_pick_from_yaw(float yaw)`

- **功能:** 从指定云台角度位置取回物块。
- **流程:** 开爪 → 到放置位 → 降到60mm → 合爪 → 抬起 → 转移到置物架(50,10,0°) → 降到抓取位(50,60,0°) → 开爪放回 → 安全转移。

### `static void act_current_platform_to_yaw(uint8_t code)`

- **功能:** 完整动作：从置物盘抓取 → 放置到指定环位置。
- **等价于:** `act_pick_current_platform()` + `act_release_to_yaw(yaw_for_code(code))`

### `static void act_pre_yaw(uint8_t code)`

- **功能:** 预置位：云台转到指定环角度，开爪等待。
- **用途:** 转盘颜色验证流程中，准备验证下一个物块。

### `static void fangzhi(uint8_t code)` 和 `fangzhi_maduo(uint8_t code)`

- **功能:** 放置物块到指定环/code位置。两者目前实现相同。
- **参数:** `code` = 1(右环), 2(中心环), 3(左环)。

### `static void na(uint8_t code)`

- **功能:** 从指定环位置取回物块到置物架。

### `static void yuantai_na(uint8_t code)` / `yuantai_na1(uint8_t code)` / `yuantai_na2(uint8_t code)`

- **功能:** 转盘区的完整取物动作。
  - `yuantai_na` — 完整抓取放置(先取后放)
  - `yuantai_na1` — 仅预置位(等待验证)
  - `yuantai_na2` — 确认后夹取带回

### `static void race_finish_stop(void)`

- **功能:** 比赛完成后的停止状态。执行器归零 → 加热关 → 底盘停 → 死循环慢闪LED(500ms)。

### `static void race_stage_read_task_order(void)`

- **功能:** **阶段1** — 发送'1'命令让上位机扫描二维码，获取任务序列。
- **流程:**
  1. 清PID积分
  2. 发送 `VISION_CMD_TASK_ORDER` ('1')
  3. 底盘前移150mm后后退530mm(进入扫码位)
  4. 等待上位机返回任务序列(20s超时)
  5. 解析 `Serial_RxPacket` → `task[0..5]`
  6. 发送到串口屏显示

### `static void race_stage_prepare_actuators(void)`

- **功能:** **阶段2** — 比赛前准备。
- **流程:** 执行器归零 → 开加热(300) → 安全转移 → 开爪 → 后退910mm → 云台转120°。

### `static void race_stage_pick_first_platform_blocks(void)`

- **功能:** **阶段3** — 第一物料平台抓取三个物块。
- **流程:**
  1. 发送'2'定位第一个物块
  2. 视觉引导移动到目标位(带MISS重试)
  3. 发送'3'获取转盘三物块颜色编码 → `ypcode[0..2]`
  4. 依次从置物盘工位1→2→3抓取(带颜色验证)

### `static void race_stage_first_ring_task012(void)` 和 `race_stage_second_ring_task012(void)`

- **功能:** **阶段4/5** — 色环区放置物块。
- **区别:** 第一阶段放完后取回；第二阶段只放不取。
- **流程:**
  1. 导航至色环区(多段PID姿态控制)
  2. 发送'7'粗定位 → 移动到位(带MISS重试)
  3. 发送'8'精定位 → 最终对准
  4. 按任务码顺序放置→(取回)三物块

### `static void race_stage_pick_second_platform_blocks(void)`

- **功能:** **阶段6** — 第二物料平台抓取三物块。
- **流程:** 与阶段3类似，但使用 `VISION_CMD_SECOND_BLOCK_*` 系列命令。

### `static void race_stage_third_ring_task345(void)` 和 `race_stage_fourth_ring_task345(void)`

- **功能:** **阶段7/8** — 色环第三圈和码垛区放置(对应task[3..5])。

### `static void race_stage_finish_drive(void)`

- **功能:** **阶段9** — 完成区行驶。导航至终点区域后停车。

### `void race_task_run(void)`

- **功能:** **比赛任务总入口**。按顺序调用全部9个阶段。
- **调用者:** `main()` 主循环中调用一次(内部各阶段顺序执行，最后死循环停止)。

### 3.1 底盘运动函数

#### `void car_move(int v_x, int v_y, int w)`

- **功能:** **麦克纳姆轮速度解算**，驱动4个底盘电机。
- **参数:**
  - `v_x` — X方向速度(正值=前进)
  - `v_y` — Y方向速度(正值=右移)
  - `w` — 旋转角速度(正值=逆时针)
- **内部:** 用麦克纳姆轮运动学公式计算4轮速度，通过CAN发送 `zdt_vel()`。

#### `void car_move_distance_x(float x)` / `car_move_distance_y(float y)`

- **功能:** 纯X或纯Y方向的位置移动(开环，不等待完成)。
- **换算:** X: `pulses = |x| × 10.5`, Y: `pulses = |y| × 10.3`
- **内部:** 调用 `zdt_pos()` 发送位置指令 + `zdt_sync(0)` 同步启动。

#### `void car_move1(float x, float y, int a_in, int car_speed)`

- **功能:** **仅Y方向移动**并等待完成(内部忽略x参数)。
- **流程:** 设置加速度/速度 → `car_move_distance_y(-y)` → `car_move_delay()` 等待。

#### `void car_move2(float x, float y, int a_in, int car_speed)`

- **功能:** **仅X方向移动**并等待完成(内部忽略y参数)。

#### `void car_move3/car_move4(float x, float y, int a_in, int car_speed)`

- **功能:** 与 move1/move2 相同但不等待完成(发完指令立刻返回)。

#### `void car_move_distance(float x, float y, int a_in, int speed_in)`

- **功能:** **通用位置移动**——先Y后X，各方向等待完成。
- **流程:** Y移动 → 等待 → X移动 → 等待。

#### `double car_move_delay(float distance, uint16_t a_of_car, uint16_t speed_of_car, uint8_t direct)`

- **功能:** **计算并等待**位置移动完成。
- **参数:** `distance`=距离(mm), `a_of_car`=加速度, `speed_of_car`=速度, `direct`=0(X方向)/1(Y方向)。
- **返回值:** 实际运动时间(ms)。
- **内部:** 梯形速度曲线时间估算，包含加速段+匀速段。

#### `void change_A(int a_in)` / `void change_SNA1(int a_in, int speed)`

- **功能:** 修改全局加速度(`a`)和速度(`car_move_speed`)参数。

### 3.2 PID控制函数

#### `void PIDInit(void)`

- **功能:** 初始化默认PID参数。
  - kp=1.5, ki=0.001, kd=2.0, maxIntegral=7.0, maxOutput=180.0

#### `void PID_Calc(PID *pid, float reference, float feedback)`

- **功能:** **PID计算核心**——输入目标值和反馈值，输出控制量。
- **角度环绕处理:** 误差>180时减360，误差<-180时加360(解决-180°/180°跳变)。
- **三项计算:** P(比例) + D(微分) + I(积分，带限幅)。
- **输出限幅:** 由 `pid->maxOutput` 约束。

#### `void PID_DIL(int v_x, int v_y, int w, uint32_t time, float target)`

- **功能:** 设置PID运动参数(不启动，仅设置)。
- **参数:** `v_x/v_y`=底盘基础速度, `w`=额外角速度, `time`=持续时间(ms), `target`=目标Yaw角。

#### `uint8_t PID_move(int v_x, int v_y, int w, uint32_t time, float target, int pid_choose)`

- **功能:** **PID姿态控制主函数**——原地旋转或边移动边转，使机器人朝向目标角度。
- **参数:**
  - `v_x/v_y` — 平移速度(通常为0)
  - `w` — 额外旋转速度(通常为0)
  - `time` — 持续时间(ms)
  - `target` — 目标Yaw角度(°)
  - `pid_choose` — PID参数组选择:
    - 0 = 转场(TRANSIT): kp=2.0, kd=0.8
    - 1 = 低输出(LOW_OUTPUT): kp=3.3, kd=1.8, maxOutput=30
    - 2 = 快速: kp=5.0, kd=5.0
    - 3 = 稳态小积分(SETTLE_KI_LOW): kp=2.0, ki=0.05
    - 4 = 稳态大积分(SETTLE_KI_HIGH): kp=2.0, ki=0.07
- **流程:**
  1. 配置PID参数
  2. `PID_DIL()` 设目标
  3. 启动TIM4(50ms周期中断)
  4. 循环: 读取IMU → PID计算 → 底盘驱动
  5. 时间到或flag置位后停止

#### `void race_chassis_tim4_callback(void)`

- **功能:** TIM4中断处理。置位 `s_tim4_tick` 标志。

#### `static void PID_tim4_run(void)`

- **功能:** 每个TIM4周期(50ms)执行一次PID控制循环:
  1. `imu_scan()` 读取角度

## 5. host_proto.c

**路径:** `STM32f407_wuliu/Core/Src/host_proto.c`
**头文件:** `host_proto.h`

### 协议说明

- 上位机→STM32: `0xFF + 9字节ASCII载荷 + 0xFE` (共11字节)
- STM32→上位机: 单字节ASCII命令(无换行)

### 函数列表

#### `void host_init(void)`

- **功能:** 初始化协议状态机。清零标志/缓冲区，启动单字节接收中断。
- **调用时机:** `main()` 中在外设初始化之后调用一次。

#### `void host_isr_rx_cplt(void)`

- **功能:** 中断上下文的接收处理。将收到的字节推进状态机，然后重新武装中断。
- **调用者:** `HAL_UART_RxCpltCallback` (HOST_UART=USART1)。
- **禁止:** 不可在主循环中调用。

#### `uint8_t host_get_rx_flag(void)`

- **功能:** 主循环轮询——检查是否收到完整帧。
- **返回值:** 1=有新包(读后自动清零), 0=无。
- **语义:** 一帧只被消费一次。

#### `uint8_t host_rx_at(uint8_t i)`

- **功能:** 读取载荷中第i字节(0~8)，越界返回0。

#### `void host_rx_copy(uint8_t *out)`

- **功能:** 拷贝全部9字节载荷到 `out` 数组。
- **前提:** `out` 至少9字节。

#### `void host_send_byte(uint8_t b)` / `void host_send_cmd(char c)`

- **功能:** STM32→上位机：发送单字节命令。阻塞发送。
- **禁止:** 不可在ISR中调用。

#### `void host_send_string(const char *s)`

- **功能:** 发送字符串(到 `\0`)，不补换行。

#### `uint8_t host_is_handshake(void)`

- **功能:** 检查当前数据包是否为握手帧 `"987654321"`。
- **返回值:** 1=是握手帧。

#### `uint8_t host_packet_eq(const char *s)`

- **功能:** 检查当前数据包是否与给定9字串逐字节相等。

### 状态机 (私有)

// State 0: 等帧头 0xFF
// State 1: 收9字节载荷

## 6. hal_zdt.c

**路径:** `STM32f407_wuliu/Core/Src/hal_zdt.c`
**头文件:** `hal_zdt.h`

### 协议说明

ZDT系列电机驱动器CAN协议。所有命令通过CAN1扩展帧发送，29位ID = `(addr << 8) | pack_number`，所有命令以字节 `0x6B` 结尾。长命令(>8字节)自动分包。

### 函数列表

#### `void zdt_set_wait_enabled(bool enabled)` / `bool zdt_wait_enabled(void)`

- **功能:** 设置/读取是否等待CAN发送完成。默认true。

#### `zdt_ret_t zdt_tx(uint8_t *cmd, uint8_t len)`

- **功能:** **CAN发送核心**——向指定地址发送命令。
- **格式:** `cmd[0]=地址, cmd[1]=功能码, cmd[2..]=数据, 末字节=0x6B`
- **分包:** 每帧最多装7字节数据，超出的自动拆多帧(每帧 `pack_number` 递增)。
- **返回值:** ZDT_OK / ZDT_ERR_ARG / ZDT_ERR_CAN / ZDT_ERR_MAIL

#### `zdt_ret_t zdt_en(uint8_t addr, bool on, bool sync)`

- **功能:** 使能/失能电机。
- **命令:** `0xF3`

#### `zdt_ret_t zdt_vel(uint8_t addr, uint8_t dir, uint16_t vel, uint8_t acc, bool sync)`

- **功能:** 速度模式控制。
- **命令:** `0xF6`
- **参数:** `dir`=方向(0/1), `vel`=速度(RPM), `acc`=加速度(0~255), `sync`=是否同步启动。

#### `zdt_ret_t zdt_pos(uint8_t addr, uint8_t dir, uint16_t vel, uint8_t acc, uint32_t clk, bool abs, bool sync)`

- **功能:** 位置模式控制。
- **命令:** `0xFD`
- **参数:** `clk`=目标脉冲数, `abs`=是否绝对位置。

#### `zdt_ret_t zdt_stop(uint8_t addr, bool sync)`

- **功能:** 急停指定电机。
- **命令:** `0xFE`

#### `zdt_ret_t zdt_sync(uint8_t addr)`

- **功能:** 同步启动——使先前缓冲的运动指令同时开始执行。
- **命令:** `0xFF`

#### `zdt_ret_t zdt_read(uint8_t addr, zdt_sys_t s)`

- **功能:** 读取电机状态寄存器。
- **可读寄存器:** `ZDT_S_VER(版本), ZDT_S_VEL(速度), ZDT_S_CPOS(当前位置), ZDT_S_ORG(回零状态)` 等。

#### `zdt_ret_t zdt_origin_set(uint8_t addr, bool save)`

- **功能:** 设置当前位置为原点。`save`=是否保存到EEPROM。

#### `zdt_ret_t zdt_home_trigger(uint8_t addr, uint8_t mode, bool sync)`

- **功能:** 触发回零。mode=2(传感器less碰撞回零), mode=3(限位开关回零)。

#### `zdt_ret_t zdt_home_abort(uint8_t addr)`

- **功能:** 中止回零流程。

#### `zdt_ret_t zdt_home_params_read(uint8_t addr)` / `zdt_home_params_write(...)`

- **功能:** 读取/写入回零参数(方向/速度/碰撞电流/持续时间/超时等)。

#### `zdt_ret_t zdt_clear_pos(uint8_t addr)` / `zdt_clear_stall(uint8_t addr)`

- **功能:** 清除电机位置计数器 / 清除堵转保护标志。

#### `zdt_ret_t zdt_stop_all(void)`

- **功能:** 依次急停电机1,2,3,4(底盘四轮)。

#### 调试函数

#### `adjust_camera_property(cap_obj, prop, delta, min, max)` → float

- **功能:** 动态调整摄像头属性(如对焦±delta)，返回新值。

### 10.4 视觉任务函数

#### `get_color_name(bgr_val)` → (str, str)

- **功能:** BGR值→颜色名称和编码。
  - Red → ("Red", "1"), Green → ("Green", "2"), Blue → ("Blue", "3")
  - 其他 → ("Unknown", "0")

#### `run_erweima()`

- **功能:** **二维码识别任务**(对应STM32命令'1')。
- **流程:**
  1. 打开二维码摄像头
  2. 循环读取帧 → 灰度化
  3. 优先用pyzbar解码，降级到OpenCV QRCodeDetector
  4. 过滤7字符数据，连续3次相同→确认
  5. 发送7字符+补零的9字节数据
  6. 失败发送 "000000004"

#### `run_wukuaiyuanxin_1()` → color_code

- **功能:** **第一圈物块定位**(对应STM32命令'2')。
- **算法:** 霍夫圆检测 + HSV颜色识别
- **ROI:** `[120,80,400,217]`
- **HoughCircles参数:** minR=35, maxR=45, param1=25, param2=25
- **稳定性:** 位置30帧内位移<10px + 颜色出现≥15次且置信度≥70%
- **输出格式:** `"{x:04d}{y:04d}{color}{radius}"` → send_data

#### `run_wukuaiyuanxin_2()` → color_code

- **功能:** **转盘第二物块检测**(对应STM32命令'a')。
- **与上面的区别:** ROI不同`[220,80,200,200]`，稳定性阈值更低(15)。

#### `run_wukuaiyuanxin_xuanzequyu(i, yanse)`

- **功能:** **指定区域颜色验证**(对应STM32命令'5'/'6'/'b'/'c')。
- **参数:** `i`=ROI选择(0=爪子区, 1=正下方A3, 2=右下角A2, 3=左下角A1), `yanse`=期望颜色编码。
- **行为:** 只在检测颜色匹配时才确认，持续检测直到稳定。

#### `run_wukuaiyuanxin_A()` → (A1, A2, A3)

- **功能:** **快速颜色扫描**——同时检测A1/A2/A3三个区域的颜色。
- **流程:**
  1. `stable_detect(A1区域)` → A1
  2. `stable_detect(A2区域)` → A2
  3. 如果A1==A2 → 重新检测(容错)
  4. A3通过排除法: `A3 = {1,2,3} - {A1,A2}`

#### `LOOP1()` / `LOOP2()`

- **功能:** **转盘颜色逻辑**——判断旋转方向并发送物块位置索引。
- **流程:**
  1. 检测当前第二个物块颜色C_2
  2. 如果C_1 ≠ C_2 → 转盘已转 → 根据A1和C_1判断旋转方向 → 计算索引
  3. 如果C_1 = C_2 → 循环等待直到颜色变化
  4. 发送 `"{INDEX}{INDEX1}{INDEX2}456789"`

#### `detect_boundary_line()`

- **功能:** **直线纠偏**(对应STM32命令'd')。
- **算法:**
  1. 1920×1080 → 灰度 → 高斯模糊
  2. Canny边缘检测(50/150)
  3. HoughLinesP直线检测
  4. 加权平均计算角度(以线段长度为权重)
  5. 3次检测方差≤1.0 → 发送角度数据: `"000000{sign}{int}{dec}"`
  6. 最多10次重试

#### `run_sehuanyuanxin2()` / `run_sehuanyuanxin2_centered()`

- **功能:** **色环定位**(对应STM32命令'7'粗定位 / '8'精定位)。
- **区别:**
  - 粗定位: 640×480, minR=35, maxR=38
  - 精定位: 1920×1080, minR=160, maxR=165
- **流程:**
  1. 霍夫圆检测 → 圆形mask
  2. HSV三色面积计算 → 确定颜色
  3. 颜色+位置双稳定验证
  4. 发送 `"{x:04d}{y:04d}{color}"`

#### `run_maduoyuanxin2()` / `run_maduoyuanxin2_centered()`

- **功能:** **码垛定位**(对应STM32命令'9'粗定位 / '0'精定位)。
- **与色环的区别:** 搜索半径更小(minR=20, maxR=27)，检测区域更大(600×200~300)。

### 10.5 命令处理器

#### `class HostSerialCommandHandler`

- **功能:** 上位机主控类，管理通信和视觉任务分发。

#### `__init__(self)`

- **功能:** 初始化运行标志和超时计时器。

#### `handle_serial_data(self, data)`

- **功能:** **命令分发核心**——根据STM32发来的单字符命令，调用对应视觉函数。

| 命令 | 调用函数 | 说明 |
|------|----------|------|
| `"1"` | `run_erweima()` | 扫二维码 |
| `"2"` | `run_wukuaiyuanxin_1()` | 第一圈物块定位 |
| `"a"` | `run_wukuaiyuanxin_1()` | 第二圈物块定位(存到C_1_loop2) |
| `"3"` | `LOOP1()` | 第一圈转盘检测 |
| `"4"` | `LOOP2()` | 第二圈转盘检测 |
| `"5"` | `run_wukuaiyuanxin_xuanzequyu(0/1, A[1])` | 验证第一圈第2个物块 |
| `"6"` | `run_wukuaiyuanxin_xuanzequyu(0/2, A[2])` | 验证第一圈第3个物块 |
| `"b"` | `run_wukuaiyuanxin_xuanzequyu(0/1, A[5])` | 验证第二圈第2个物块 |
| `"c"` | `run_wukuaiyuanxin_xuanzequyu(0/2, A[6])` | 验证第二圈第3个物块 |
| `"7"` | `run_sehuanyuanxin2()` | 色环粗定位 |
| `"8"` | `run_sehuanyuanxin2_centered()` | 色环精定位 |
| `"d"` | `send_data("000000000")` | 直线纠偏(预留) |
| `"9"` | `run_maduoyuanxin2()` | 码垛粗定位 |
| `"0"` | `run_maduoyuanxin2_centered()` | 码垛精定位 |
| `"end"` | `self.running=False` | 任务完成 |
| `"r"` | `restart_program()` | 重启上位机 |

#### `run(self)`

- **功能:** **上位机主循环**。
- **流程:**
  1. 打开串口
  2. 打印启动信息
  3. 发送握手帧 "987654321"
  4. 循环接收命令 → `handle_serial_data()`
  5. 300秒无数据警告
  6. Ctrl+C优雅退出，释放所有资源
